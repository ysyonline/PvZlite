## 二、本版变更（相对 v2.3.1）

### 2.1 咬碑藤（gravebuster）—— 补齐清碑手段

v2.3.1 墓碑机制留下硬缺口——玩家毫无清碑手段。本版补上这把钥匙。

| 项 | 值 |
|---|---|
| cost | 75（50 被论证否决——排雷退化为开局流程） |
| cd | 7.5s |
| dur | 300 |
| 咀嚼时长 | **4.0s**（须短于被啃死 4.615s；8.0s 被否决——永远啃不完） |
| 清碑 | **+25 积分不返阳光** |
| 受击 | 咀嚼冻结（`hurtThisFrame` 四点时序链） |
| 解锁 | 2-5 |

### 2.2 猫王僵尸（elvis）+ 伴舞（backup）

| 项 | 值 |
|---|---|
| elvis | `STATS[900,14]`、击杀 300 分 |
| backup 伴舞 | `[120,20]`、25 分 |
| 首召 | 3.0s |
| 间隔 | 按难度 **9.0/7.5/6.0s**（三难度唯一差别） |
| 每次 | 3 只 |
| 上限 | 伴舞 6、本体 2 |
| 本体死 | 伴舞 crumble 0.8s 不计分 |
| 注入 | `ELVIS_WAVES` 编排（2-5/2-7/2-9/2-10，共 11 只）；**严禁进 `GRAVE_SPAWN_POOL`**（同波多只精英方差灾难） |

### 2.3 W2 补真 10 波骨架（裁决 B）

- `WAVE_TEMPLATES[2]` 弃借 1-1 锚（5 波）→ W2 墓地专属十波骨架：三幕对齐 1-10/3-10（W3/W6/W10 big），出怪量较 1-10 调轻约一成（base 47 vs 53）
- 猫王编排零改动恒等还原：tw=10 ⇒ `idx=round((n-1)*(tw-1)/9)` 恒等，2-5 W6×1 / 2-7 W5×1+W9×1 / 2-9 W4×1+W8×2 / 2-10 W3×1+W7×2+W10×2，合计恰 11 只
- 等比压缩式保留为防御性兜底

### 2.4 世界 2 后 6 关开放（2-6~2-10 金币关）

- 波表策略：共用 `WAVE_TEMPLATES[2]` 十波骨架，不逐关手调（世界 1/3/4 同款先例）
- CARDS 20 张已全发完 ⇒ 2-6~2-10 无新卡可发，走世界 3 同款金币管道（每关 100，v2.1 T-104 结算链路原样通用）
- 世界 2 全 10 关可玩；占位仅剩世界 4 九格

### 2.5 世界 1 后五关改昼（1-6~1-10）

- **用户反馈**：夜段产阳光太慢（天空不掉+向日葵 24s），第 2 波就感觉压力、曲线跳变太大
- 五锚点 `time:'night'`→`'day'`、name、lawn 换昼板、去 `night:true`；startSun 100/150 口径保留不动
- 天空掉阳光/向日葵 20s 等经济机制全走 `level.time` 通用判定，零机制代码改动

### 2.6 连带变更

| # | 变更 | 说明 |
|---|---|---|
| 1 | 卡池 19→20 | 咬碑藤入池；SMOKE-025/027/029 + REG-TESTMODE-01 基线同步 |
| 2 | 门控用例 | 新增 **REG-ELVIS-01**（10 波契约 + 注入恒等 + 非编排波零残留 + 三幕 big 恰 3 锁）；REG 总数 68→69 |

**零其他变更声明**：僵尸基础属性（elvis/backup 除外）/ 既有植物属性 / 伤害公式 / 解锁拓扑 / testMode 纯沙盒零写守卫，与 v2.3.1 完全一致。
