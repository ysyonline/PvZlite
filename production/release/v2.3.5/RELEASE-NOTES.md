## 二、本版变更（相对 v2.3.4）

### 2.1 墓碑钻怪波次爬坡（方案 A 拍板）

- 新常量 `GRAVE_SPAWN_RAMP={1:0,2:0,3:0.15,4:0.15}`（~L122）
- `newWave` 钻怪判定改查表（`pct=RAMP[n]??GRAVE_SPAWN_PCT`，~L2182）
- **W1/W2 纯教学观察窗 0% → W3/W4 半压 15% → W5 起全额 30%**，碑怪回归中期压力源定位

### 2.2 2-1~2-3 前三排禁碑

- `materializeLevels` 墓碑 LCG 生成加 `if(l<=3&&col<3)continue` 重掷（~L763）
- 咬碑藤到手前无清碑手段不再被挡死；实测 2-1/2-2/2-3 前三排 0 座（改前 1/4/1），2-4/2-5 不受约束，无死循环

### 2.3 奖励调换

- `CARD_AWARD`：`'2-4':'gravebuster'`（原 2-5）、`'2-5':'hypnoshroom'`（原 2-4）
- 清碑刚需与禁碑放开同关衔接；魅惑菇与猫王首秀同关主题契合
