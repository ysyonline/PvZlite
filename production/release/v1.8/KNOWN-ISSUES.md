## 方法论沉淀（本版新增 · 建议纳入固定动作）

1. **「用户口述规则」与「实现假设」可能同名不同义，命名须立纪律** —— 同格锁字段初拟名 `sameCell`，与项目内既有「土豆雷」概念**撞名**（会造成检索歧义），改为 `splashGrid`。⇒ 新增跨模块字段前先做名称占用检索。
2. **定版刀必须做「版本标签通扫」，而非只改 L49** —— 验收脚本/规格文档里的**活默认值**（`PVZ_EXPECT_VER` 缺省值）不改，定版后复跑会**假红**（`indexOf` 判定对 `v1.8.0` 源码 + `v1.8.0-wip` 期望必然不匹配）。本版定版刀同步 4 处活默认值（prelude / v17-acc / r9a-spec / r9b-cal），并在定版提交前**验证改后可运行**。历史记录（plan / decisions / 报告）**保持原貌不动**。
3. **「假绿」有两类形态，都要用非零正样本断言封死** —— ①**恒等式空真**（0=0 恒真，如 selftest 的溢出断言）②**分类值覆盖键**（对象字面量重复键导致分类字段被覆盖，如 `noteHpWrite` 的重复 `kind`）。⇒ 自检断言的输入必须是**非零正样本**，并配**独立验证器**交叉核验。
4. **测量的隐含前提应升级为「域判定 + 哨兵双域回归」机器闸门** —— v1.7 教训（计数口径隐含前提随参数失效）在 v1.8 制度化：`preconditions.domain.projectionBranchEnabled` + 哨兵双域（v1.6 域 PASS / v1.7 域 FAIL）⇒ 参数一改即报警，防代数投影前提静默失效复发。
5. **口径换用必须换并集公式** —— R9-b 首轮把 prelude 的**互斥** `chillFrac` 代入**独立**并集公式 `1−(1−f)(1−s)`，虚增残差 ~12pp。⇒ 跨口径（互斥 / 重叠）数字禁止直接套用同一公式，换算规则须显式登记。
6. **小样本对照必须同种子配对比较** —— R9-b 的「warm8 方向翻转」是多锚点混看造成的抽样伪影，同种子子集对比后方向一致（全部 +0.9~+2.3pp）。
