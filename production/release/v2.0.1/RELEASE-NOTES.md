## 二、本版变更（相对 v2.0.0）

| # | 变更 | 类型 | 说明 |
|---|---|---|---|
| 1 | **`?test=1` 解「锁定」闸** | 修复（测试工具链） | 三处前置 `!testMode`：① 选关页点关解锁检查（onClickSelect L1272）——testMode 下锁定关可点进 deck 开局；② 结算屏「下一关」解锁检查（onClickEnd L1319）——testMode 下世界内连续推进不受锁限制；③ 选关页锁定格视觉（drawSelect L3441）——testMode 下按可玩亮色渲染（所见即可点）。动机 = v2.0.0 后测试侧反馈：40 关注册表下锁定关的视觉/机制/波次无法用 test 沙盒直验，须先手工推解锁进度 |

**零其他变更声明**：占位关拦截（选关页 L1271 / 结算屏 L1318 的「该关卡即将开放」toast）**保留不动**——占位关永远不可玩（Q-3/Q-12 决策），与解锁闸无关；波次表 / 阳光经济 / 冷却 / 伤害 / 存档结构（`pvz_progress_v2`）/ testMode 纯沙盒零写守卫，与 v2.0.0 完全一致；无新卡、无新关、无新机制。
