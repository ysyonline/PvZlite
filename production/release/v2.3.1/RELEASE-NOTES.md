## 二、本版变更（相对 v2.3.0）

### 2.1 蘑菇发卡落点实装（方案 A）

| 关 | 发卡 | 说明 |
|---|---|---|
| 3-1 | 小喷菇 | `CARD_AWARD` 键 `PLACEHOLDER`→`puffshroom` |
| 3-2 | 阳光菇 | →`sunshroom` |
| 3-3 | 大喷菇 | →`fumeshroom` |
| 3-4 | 魅惑菇 | →`hypnoshroom` |

- 占位计数 19→15；v2.3.0 遗留「四蘑菇普通模式不可获得」闭环。
- ⚠️ 本版蘑菇奖励落世界 3 昼段（3-1~3-4 为 day），白天沉睡不可用，需等 3-6 进入夜段——方案 A 既定设计（后续 v2.3.4 世界 2 全改黑夜后此矛盾消解）。

### 2.2 世界 2/3 互换（墓地 ↔ 泳池）

用户要求暗夜墓地与世界 3 泳池在大地图上位置互换——先暗夜墓地（世界 2），再到昏暗泳池（世界 3）。纯机械互换，零逻辑变更：

- `WORLD_THEMES[2]/[3]`、`WORLD_SHORT[2]/[3]`、`SEL_TAB_TIME[2]/[3]` 互换
- `_ANCHORS '2-1'~'2-10'` → `'3-1'~'3-10'`（泳池锚点全迁世界 3）
- `materializeLevels()` 的 `w===2/3` 全部对调；`WAVE_TEMPLATES[2]` 借 `_ANCHORS['1-1']`（墓地无锚点暂借草地）、`[3]` 引用 `_ANCHORS['3-1']`
- `CARD_AWARD`：`'2-x'`（100 金币）↔ `'3-x'`（蘑菇/PLACEHOLDER）互换
- 副作用：蘑菇奖励现落世界 2 昼段（2-1~2-4 day，沉睡不可用，等 2-6 夜段）

### 2.3 世界 2 墓碑机制（Q-7）

设计拍板：**只补机制不动占位**——2-1~2-4 已有真卡可玩，2-5~2-10 保持 PLACEHOLDER（后 6 关开放留待 v2.3.2）。

1. **占格挡种植**：`canPlant(c,g)` 规则表新增首条 `onGrave`（`level.graves` 内 `col===g.x&&row===g.y` 命中即拦，msg='墓碑挡住了这格'）；置于 occupied 之前，零副作用保护不变
2. **波次钻怪**：新增常量 `GRAVE_SPAWN_PCT=0.30` / `GRAVE_SPAWN_POOL`（加权 normal6/cone2/fast2/bucket1）；`newWave()` 末每波遍历墓碑、每碑独立 30% 概率抽取类型 push 入 spawnQueue
3. **碑位出怪**：`processSpawnQueue` 识别 `_graveCol` 标记 → 僵尸从碑列 x 钻出（而非屏幕右缘）
