## 方法论沉淀（本版新增）

1. **QA 门三项评分体系** —— v2.2 首次建立「机制级 REG（锁定核心行为契约）+ 真机视觉 CDP（像素判据/帧异常/hash 互异）+ 平衡画像（多臂对照 bot 跑分）」三层评分，**弥补了 v2.1 的 GDD→实现「裸奔」**（前一版三新卡实装后零机制级用例就提交了）。

2. **跨成员不一致必须主理人中转** —— QA 侧只登记不改 GDD，工程侧只改代码不动文档 → 主理人转派策划侧修订（V22-DOC-01），避免互相越界。本版实操：品质→主理人→策划 三跳转。

3. **子代理 spawn 返回空输出 ≠ 失败** —— 本版三次派单中有两次工具返回空，但产物已落盘。**主理人必须亲自 `git status` + 核对目标文件再判定**，不能凭返回内容下结论。

4. **bot 校准三步（画像类必备）** —— 画平衡像前必做三道校准门：G0 复现门（前版本报告 4 种子逐关对账）→ G1 通关门（bot 基线臂能打通）→ G2 生效门（新卡被实际购买并使用）。v2.2 平衡画像仅 3 条校准就发现 3 个 bot 策略 bug——**校准未修前的数据一律不采信**。

5. **⚠ 锚点缺键静默模板化**（v2.1 M3 最值钱发现，纳入长期沉淀）—— `_ANCHORS` 缺键不报错、关卡照常可玩，内容却与模板关**逐字节相同**；只有难度画像能发现。**凡改锚点必断言该关 waves ≠ 模板关**。

6. **派单铁律：目标数值 vs 操作方案二选一**（v2.1 沉淀）——混写「fast 移到 W2」与「−140」致歧义（移=净 0 / 删=−140）。以后派单只给一端。

7. **判别力自证三件套**（历代沿革）——① 新源 PASS（证明实现正确）② 旧源 FAIL（证明旧缺陷真实存在）③ 旧 fail 落点必须在**机制本身**（而非卡片不存在等无关原因）。三新 REG 均满足。**不做旧源自证 = 可能修了不存在的 bug**。
