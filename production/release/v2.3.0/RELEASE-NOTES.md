## 二、本版变更（相对 v2.2.8）

### 2.1 夜行机制（基础设施）

| ID | 标题 | 变更 |
|---|---|---|
| **N1** | 夜行判定与白天沉睡 | 新增 `isNocturnal()`（阳光菇/小喷菇/大喷菇/魅惑菇四类一次写全），复用既有 `_isNight` 口径（`level.time==='night'\|\|'fog'`），**即时判定不新增 asleep 字段**。白天完全禁用（不产/不攻/不触发），`updatePlant` 沉睡分支即时 return |
| **N2** | 白天沉睡视觉（U8 补绘） | 四菇绘制分支插入 `if(asleep){沉睡绘制}else{原清醒路径}`，**纯新增 116 行、清醒路径零字符改动**（夜晚/浓雾逐像素不变）。表现：菇盖下移 5px + 竖向压缩 0.84→0.60 + 主色降亮 + 半闭眼细线 + zzz（魅惑菇无半闭眼——盖面为催眠螺旋，设计例外） |
| **N3** | 「☾ 夜行」角标（U10） | 抽共享函数 `drawNocturnalBadge`，**两处同源调用**（选卡页 + 对局内卡栏），满足「draw/hit 同源」铁律 |

### 2.3 魅惑状态机（U4，独立解耦）

- 僵尸新增 `hypno` 字段（**本版唯一动 probe 快照白名单处**：zombiesArr 增 `hypno`）
- 被啃食触发（非踩中）；魅惑后 `spd` 反向、攻击敌方僵尸
- 互啃 **65/s 连续帧结算**（复用啃食系数，免新增计时字段）；被魅惑僵尸越右缘即消失
- **Q-5 口径**：魅惑击杀计玩家分、被反杀不计分
- **Q-2 口径**：免疫名单 `HYPNOSHROOM_IMMUNE` 记位不实装（本版无免疫对象）
- 被魅惑僵尸**紫描边**视觉（tint 叠加冰冻/黄油后仍可辨识，真机像素判据验证）
