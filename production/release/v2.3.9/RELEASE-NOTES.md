## 二、本版变更（相对 v2.3.8）

### 2.1 魅惑僵尸互啃观感修复（用户反馈）

用户反馈「回头僵尸不能吃植物只能吃过来的僵尸」。逻辑层排查确认本无啃食植物路径（REG-MUSH-04 [4][5] 已锁），真因是**互啃观感**：互啃双方 `eating=false` 嘴不动，加上啃植物同款 chomp 音效，被误读为「在吃植物」。

- **修复**：互啃双方 `eating=true` 张嘴互殴 + 接触中点火花粒子（dt 概率 ≈0.6 粒/s）
- **REG-MUSH-04 [6]** 断言同步：`foe.eating===true && zD.eating===true`
- **消缺方法论**：用户报「A 在做 B」先注入式逻辑复现，无法红 = 观感问题修观感（本次为观感修复，非真视觉缺陷）

### 2.2 小喷菇柄可见 + 接地（用户反馈）

用户反馈「根茎看不见 + 悬浮腾空不落地」。旧柄 `capR*1.15≈13.8` 整根藏进菇盖内（盖底缘 10.1），且悬空 22px。

- **修复**：`PUFFSHROOM_GEOM` 增 `stemW:2.64` / `stemH:34`——柄底地面线锚定（与阳光菇柄底同线）+ 柄绘制提到沉睡/清醒分支之前共用（旧沉睡分支无柄）+ 卡面柄同步 ×0.82 缩放
- 新增 **REG-MUSH-05**（stemH≥34 / 露出盖底缘>8px / 双姿态真帧无异常；旧源必红）
- 真机视觉 `_v239-puffshroom-stem.js` **4/4**（旧 v2.3.8 源 0/4 全红判别力 ✓）
- harness 桥：`PUFFSHROOM_GEOM` + `__renderRaw`
