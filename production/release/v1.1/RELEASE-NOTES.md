### 系统能力

- **WebAudio 实时合成音效 + 背景音乐（BGM）**：全程零音频文件，音色由代码合成；主音量总线 + 战斗 / 事件 / UI / 环境 4 条分组总线，音效路由 **21 键**（v1.0.0 为 13 键）。
- **大波警报循环**：预警期内警报按 0.62s 一轮首尾相接循环（2 秒窗口约 4 轮，200ms 淡出），与横幅同起同停，填满原「一次性三连」留下的听觉空白。
- **铲子**：点左侧铲子槽或按 `X` 进入铲除模式，再点目标植物。
- **`localStorage` 存档 · 3 键**（v1.0.0 仅 1 键）：关卡解锁 `pvz_unlocked`、**静音偏好 `pvz_muted`（新）**、**历史最高分 `pvz_highscore`（新）**，读写统一带 `try/catch` 兜底，隐私模式 / `file://` 受限时不中断游戏。
- **内嵌版本号（新）**：源码 `VERSION` 常量 + 控制台启动输出 + 菜单角落版本小字，仅凭文件本身即可判定版本。
- **关卡直进通道**：URL 追加 `?level=N` 可免解锁直接进入第 N 关（v1.1 支持 1–3；便于演示与验证）。
- **波次清场门槛**：上一波僵尸未清空，不会强推下一波（避免两波夹击）。
- **大波预警**：大波到来前播放「一大波僵尸正在逼近！」横幅 + 循环警报 + 冲击音，预警时长 2 秒，预警期内不刷怪。
- **完整快捷键体系**：`1`–`6` 选卡 · `X` 铲子 · `空格` 暂停 · `Esc` 取消 · `F` 加速（1x/2x/4x）· `M` 静音 · `R` 返回菜单（对局中二次确认）。
