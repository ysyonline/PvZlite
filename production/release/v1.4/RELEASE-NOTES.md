### 运行方式

双击 `plants-vs-zombies.html`（`file://` 协议）或拖入浏览器窗口即可。无需安装、无需 Node、无需联网。首次进对局后点一次草坪/阳光解锁音频（游戏内已做兜底）。关卡从主菜单进入，或以 `?level=N` 直进；点「开始游戏」直接进入选卡界面（两排布局：上排待选卡池 / 下排卡槽栏）。

### 工程与测试

- 配置表驱动硬约束：`POINT_CONFIG` / `SLOT_CONFIG` 双表（含 `DEATH_COIN_FX`），未来加地图/积分渠道只加数据不改逻辑。
- 核心语义变更：`selected.i` = deck 槽位（非 CARDS 下标），种植按 `selected.type` 经 `CARDS.find` 解析（REG-TRAP-04 / REG-CARD-* 等价迁移锁定）。
- 门控扩容：烟雾 28→**29**（SMOKE-029 十槽布局）；回归 67→**81**（+META×2 / SLOT×4 / CLEAR / POINT×2 / HUD 等新用例，含 REG-POINT-06 爆币特效）；总线 56 零新键（收集音复用 cardReady）。
