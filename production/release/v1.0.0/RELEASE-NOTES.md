### 系统能力

- **WebAudio 实时合成音效 + 背景音乐（BGM）**：全程零音频文件，音色由代码合成；含主音量总线与 4 条分组总线（战斗 / 事件 / UI / 环境）。
- **铲子**：点左侧铲子槽或按 `X` 进入铲除模式，再点目标植物。
- **`localStorage` 解锁存档**：键 `pvz_unlocked`，通关第 N 关永久解锁第 N+1 关，刷新后仍生效。
- **第二关直进通道**：URL 追加 `?level=2` 可免解锁直接进入第二关（便于演示与验证）。
- **波次清场门槛**：上一波僵尸未清空，不会强推下一波（避免两波夹击）。
- **大波预警**：大波到来前播放「一大波僵尸即将来临！」横幅 + 警报音，预警期内不刷怪。
- **完整快捷键体系**：`1`–`6` 选卡 · `X` 铲子 · `空格` 暂停 · `Esc` 取消 · `F` 加速（1x/2x/4x）· `M` 静音 · `R` 返回菜单（对局中二次确认）。

### 音频与体验根治

- **音频无声问题根治**：新增「超声保活音源」（17.5kHz 直连输出，防止系统驱动静音门控吞掉首个音效）+ 音频上下文预热 + 未就绪时自动补播队列，开局第一声必定可闻。
- **背景音乐上线**：对局期 BGM 自动播放，返回菜单自动停止，静音键统一管控。
- **波次清场门槛**：上一波清空才开新波，杜绝「上一波没清完又涌一波」的两波夹击。

## 四、变更日志（Changelog）

> **口径说明**：以下条目**全部有 git 提交支撑**，不含编造内容，不罗列提交 sha。
> 本仓库 git 历史起点为 **2026-09-15 的「Phase 6.5 基线快照」**（该提交已包含音频总线、噪声缓冲预生成、圆角矩形等已落地能力）。Phase 1–5 的「从零实现」阶段发生在仓库初始化之前，**无可追溯提交**，故不在本日志中；其功能全貌见「二、功能清单」。
> 统计区间：2026-09-15 ~ 2026-09-16，共 **36 个提交**，其中 **26 个为功能/修复/文档提交**、**10 个为纯会话归档提交**（无代码变更）。

### 4.1 新增功能

- 新增 **`Easing` 缓动库**，作为种植动画 / 爆炸冲击波 / 屏幕震动的公共依赖。
- 新增 **屏幕震动系统**（`triggerShake` / `triggerFlash` / `getShakeOffset`），渲染层统一位移包裹，含振幅钳制。
- 新增 **种植动画**：620ms 三段式（飞向格子 / 缩放过冲 / 落定微抖）+ 220ms 落地尘土粒子。
- 新增 **僵尸死亡零件**：按僵尸类型分派 6–7 块零件，带翻滚物理与末期淡出，含 500 上限双保险。
- 新增 **爆炸冲击波五层时间轴**：白闪 80ms / 圆环 380ms / 三色火球 450ms / 粒子 24+20+8 / 震颤 300ms。
- 新增 **大波预警增强**：末秒画面压暗、倒计时数字放大等宽、脉冲加倍、周期轻震。
- 新增 **UI 圆角化**：圆角矩形 helper（原生 `roundRect` + `arcTo` 退化），应用于卡片栏、铲子槽、冷却遮罩、两处 HUD 面板、预警进度条。
- 新增 **第二关直进通道**：`?level=2` 免解锁直进 + `unlockedLevel` 持久化到 `localStorage`（键 `pvz_unlocked`）。
- 新增 **背景音乐（BGM）**：对局期间播放，随状态机启停。
- 新增 **音频未就绪补播机制**：音效排程拆分为 `scheduleTone` / `scheduleNoise`，经 `scheduleOrDefer` 守卫，上下文非运行态时入队（上限 32）并在主循环每帧补播。
- 新增 **超声保活音源**：17.5kHz / 音量 0.005 常驻振荡器直连输出，防止驱动层静音门控吞掉开局首音。
- 新增 **音频总线架构**：`AudioBus` / `masterGain` + 战斗 / 事件 / UI / 环境四条分组总线，`muted` 通过主闸统一控制。
- 新增 **代码地图工具**：`tools/gen-code-map.mjs` 生成 `docs/code-map.md`（分区 / 函数 / 常量 → 行号区间 + 高频改动速查表），供后续低成本定位改动点。

### 4.2 问题修复

- 修复 **`SFX.bigWaveImpact` 未定义**导致的静默异常（S1）：大波真正刷怪那一帧抛 `TypeError`，被主循环整帧 `try/catch` 吞掉，玩家侧仅表现为底部红条 + 丢一帧；按音频规格补齐实现。
- 修复 **开局首个音效被吞**：音频上下文创建即预热 1 帧静音缓冲 + 音效加 8ms 前瞻 + 首次手势兜底 `resume`。
- 修复 **大波预警横幅残留**：拆分 `warn.pending`，横幅只管显示、倒计时归零立即隐藏，`pending` 负责等清场后刷怪。
- 修复 **音频未就绪时音效丢失**：以补播队列替代「直接丢弃」。
- 修复 **音频无声**（用户两次反馈）：以超声保活音源根治。
- 修复 **BGM 不可闻**（用户反馈）：重做 BGM 可闻性。
- 修复 **覆盖种植**：已占用格子不能重复种植（改为拒用提示 + 保留当前选中）。
- 修复 **波次推进**：加入清场硬门槛，杜绝上一波未清就开新波。
- 修复 **`lastDt` ReferenceError**（S0）：种植动画引入后，渲染层每帧读取的 `lastDt` 未定义；改为主循环每帧刷新全局 `lastDt` 供渲染兜底。

### 4.3 平衡与手感调整

- **大波预警时长**：4s → 3s →（最终）2s，进度条比例与提示文案同步。
- **大波预警提前触发**：上一波队列放完且场上僵尸 ≤2 只时立即预警，不再干等固定波间空档。
- **第二关温和削峰**：初始阳光 100 → 150（对齐第一关）；僵尸总量 28 → 25；首大波快速僵尸 3 → 2；终波 8 → 6 只；各波刷怪间隔放宽 1 秒。
- **全局节奏放宽**：最后两波波间空档 16s → 20s；刷怪间隔下限 1.5s → 2.5s（队列 > 6 时再 +0.5s）。
- **清场喘息**：清场快时波间保留最小喘息 12 / 16 / 20s；未清场仅允许队列放完 25s 兜底放行（防止啃坚果卡死对局）。
- **结束画面去除屏幕震动**：僵尸进屋失败（8px）与通关（2px）两处触点移除，游戏内爆炸 / 大波预警震动保留。

### 4.4 测试与工程基建

- 建立 **无头测试脚手架**（`vm` + Canvas Proxy stub + `__probe` / `__api` 探针），零 npm 依赖。
- **烟雾用例扩至 19 条**（`SMOKE-001` ~ `SMOKE-019`），覆盖状态机、卡片冷却、阳光经济、通关解锁、暂停分支、波次清场门槛、L2 平衡契约、音效调用完整性、开局音频可听性、预警横幅生命周期、音频补播、超声保活、覆盖种植、BGM 生命周期。
- 建立 **音频总线核验**（`verify-bus.js`，47 项断言）：幂等安全 / 路由完整 / 异常隔离。
- 新增 **代码地图** 生成器与「先查表定位、禁止全文读」的改动规范。
- 建立 **Playtest Round 1 执行包**（V1–V8 专项验收点 + T1–T9 任务 + 判定标准），并修正了测试计划中的过期前提。
