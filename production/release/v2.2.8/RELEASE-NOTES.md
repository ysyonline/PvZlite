## 二、本版变更（相对 v2.2.7）

### 2.1 向日葵日夜间隔有别（行为修正）

| ID | 标题 | 变更 |
|---|---|---|
| **C1** | 夜晚向日葵产阳光变慢 | 旧行为：白天夜晚一律 20s。新行为：**白天 20s / 夜晚与浓雾 24s**（对齐原版 PvZ 夜晚 24s 周期）。实现：新增常量 `SUNFLOWER_FIRST=7` / `SUNFLOWER_DAY=20` / `SUNFLOWER_NIGHT=24`；`updatePlant` sunflower 分支按 `level.time` 选择重置值；`p.sunT<1e-9` epsilon 守卫（防 `140×0.05` 累加后 `≈1.65e-14` 浮点假零触发假阴） |

### 2.2 夜晚/浓雾天空不掉阳光（行为修正）

| ID | 标题 | 变更 |
|---|---|---|
| **C2** | 夜晚天空自然掉落阳光移除 | 旧行为：夜晚天空照常掉阳光。新行为：`checkWave` 的 sunFallT 到期分支加 `level.time==='day'` 守卫——**仅白天**天空掉阳光，夜晚/浓雾不再掉落。与 C1 共同收紧夜晚经济，为 v2.3 夜行蘑菇体系铺垫 |

### 2.3 连带

| # | 变更 | 说明 |
|---|---|---|
| 1 | REG-PLANT-01 重写 | 三段式：S1 白天 7s 首产/20s 周期 · S2 夜晚 7s 首产/24s 周期 · S3 天空不掉阳光 + 白天对照。常量走 `sb.__consts.SUNFLOWER_*` 桥，不硬编码 |
| 2 | harness `__consts` 扩展 | 新增 `SUNFLOWER_FIRST/DAY/NIGHT` 三常量桥 |
| 3 | 定版刀（`2da4410`） | `VERSION` → `v2.2.8`（919447e 曾漏改，定版刀补齐）+ prelude/v17-acc/v18-acc 活默认值同步 + code-map 刷新（**4401 行** / 21 分区 / 105 函数 / **78 常量**） |

**零其他变更声明**：关卡波次表（`_ANCHORS`）/ 伤害公式 / 植物属性（除向日葵产阳光间隔外）/ 僵尸属性 / 解锁拓扑（keyOrd 线性）/ 奖励表（`CARD_AWARD`，v2.2.7 已定）/ testMode 纯沙盒零写守卫，与 v2.2.7 完全一致。
