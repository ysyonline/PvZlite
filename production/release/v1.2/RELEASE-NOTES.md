> 第四关波次构成（源码 `LEVELS[4]` 核实，SMOKE-025 锁定）：逐波 3/3/5/5/4/5/7/8 只 = 38 只（normal 16 / cone 10 / fast 8 / bucket 4）。两幕结构：W1–W5 无铁桶、W6 铁桶回归、W8 **双铁桶压轴**（地狱难度 1008 血 ×2，系列最重压力点）。`startSun=150` 刻意高于 L3 的 100，补偿水税（水行植物必须先垫 25 费睡莲）。

### 难度 · 3 档（与 v1.1.0 一致）

普通 / 困难 / 地狱，只影响僵尸**血量**（×1.0 / ×1.35 / ×1.80）与**速度**（×1.0 / ×1.15 / ×1.30）。

### 系统能力（在 v1.1.0 基础上）

- **WebAudio 实时合成音效 + BGM**：音效路由 **22 键**（v1.1.0 为 21 键，新增 `splash` 入水声）。
- **泳池地形系统（新）**：`WATER_ROWS=[1,3]` 行级水域；水面渐变 + 相位波纹动画（暂停自动冻结）；僵尸水行下半浸色偏 + 腰线亮带。
- **入水反馈（新）**：僵尸越过草坪右缘入水瞬间 → 14 粒水花粒子 + 水色扩散环 + 「哗」溅水声；跋涉途中约 0.8s 一次小涟漪（帧率无关）。
- **铲除返还（新，v1.2 起生效于全部关卡）**：铲掉植物返还卡价一半（向下取 25 的倍数、保底 25）——豌豆返 50 / 睡莲返 25 / 向日葵·坚果返 25 / 双发返 100 / 西瓜返 75，toast 提示。
- **4x 倍速跨局保留（修复）**：菜单选的加速档位进关不再被静默重置。
- **铲子**：作用于格内**最上层实体**——垫+植物先移植物留垫；空垫直接移除；陆地格照常。
- **`localStorage` 存档 · 3 键**：关卡解锁 / 静音偏好 / 历史最高分（与 v1.1.0 一致）。
- **内嵌版本号**：`VERSION` 常量 + 控制台启动输出 + 菜单角落版本小字。
- **关卡直进通道**：URL 追加 `?level=N` 可免解锁直接进入第 N 关（v1.2 支持 1–4）。
- **完整快捷键体系**：`1`–`7` 选卡 · `X` 铲子 · `空格` 暂停 · `Esc` 取消 · `F` 加速（1x/2x/4x，**跨局保留**）· `M` 静音 · `R` 返回菜单（对局中二次确认）。

## 三、v1.2 玩家可感知的新增亮点

### 1. 第四关「泳池」

- 8 波 38 只僵尸，**两幕结构**（前 5 波无铁桶 → 后 3 波铁桶回归 → 双桶压轴）；
- **水行战场**：第 2/4 行为水域，先铺睡莲再布防——「水税」带来全新的资源规划维度；
- **水面动态渲染**：渐变底色 + 相位波纹 + 水陆交界亮边，暂停时波纹冻结（游戏时间驱动）；
- **僵尸半浸**：水行僵尸下半身水色叠加 + 腰线亮带，剪影清晰可读。

### 2. 睡莲卡（第 7 张卡）

- 25 费低门槛地基卡，唯一的「种在土里以外」的植物；
- 垫上可连种（同帧两次落格契约）；垫被啃穿则其上植物陪葬——保护垫就是保护火力。

### 3. 入水音画反馈

- 僵尸入水「哗」溅水声 + 水花粒子 + 扩散水环；跋涉途中偶发涟漪——水域不再是无声的静态贴图。

### 4. 铲除返还（全关卡）

- 铲植物不再白铲：返还一半卡价，误种有救、换阵有底气。

### 5. 4x 倍速跨局保留

- 菜单点好 4x，进哪关都是 4x（v1.1.0 中会被静默重置回 1x，但按钮显示不更新——已修复）。
