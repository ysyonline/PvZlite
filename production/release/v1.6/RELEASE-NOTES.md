## 二、本版变更（相对 v1.5 · 五刀）

### 刀① bug1 · 结算屏震动永久抖动（修复）

**症状**：对局结束进入结算屏后，屏幕震动/白闪**永不衰减**，结算画面持续抖动。
**根因**：震动（`screenShake`）与闪光（`flashT`）的衰减代码原在 `update()` 内，而 `update()` 仅 play 态执行——end 态无人驱动衰减。
**修法**：衰减逻辑迁至主循环 `loop()` **无条件段**，覆盖 menu / play / end 三态。真机验收 A1–A3 证真：三态触发后均单调衰减至 0、画面完全静止（帧差=0）。

### 刀② bug2 · 屋顶斜坡列直射穿墙（修复）

**症状**：屋顶关斜坡列（col0–4）的直射手（豌豆/寒冰/双发）弹体**贴坡直线飞行可命中坡上僵尸**，违背「斜坡挡直射」的地形设计。
**修法**：唯一判定口径 `level.roof && p.col < ROOF_COLS`（**禁用 `liftX>0`**——平台列 col6 自身 liftX 亦=60，会误伤）。斜坡列直射弹标记 `slopeWall=true`，撞壁消失（保留开火动作与音效），三判据：①坡面相交 ②坡顶折角立面 xt=505 ③最小飞行 30px。**投掷类（cabbage/melon/icemelon/corn）免疫**（走抛物越过坡面）；平台列（col5–8）直射照常命中。

### 刀③ corn · 玉米投手黄油重做（重做）

v1.5 的 corn（150/30/2.6s 常规溅射投手）推翻重做，回归原作「黄油控制」定位：

| 项 | v1.5 | **v1.6** |
|---|---|---|
| 阳光 cost | 150 | **100** |
| 单发伤害 | 30 | **15** |
| 射击间隔 | 2.6s | 2.6s |
| 溅射 | 30px · 40% | 30px · 40%（溅射伤 6） |
| **黄油弹** | 无 | **25% 概率（发射时掷定）→ 命中完全定身 2.5s** |

- **完全定身** = 移动 / 啃食 / walk 动画**三停**（对照 chill 的 ×0.6 减速），与 chill `slowT` **独立并存、互不覆盖、各自计时**，冻结优先。
- **仅直中定身**：溅射波及不施加（主理人拍板口径）。
- 弹体双形态：黄油弹 = 白奶酪块 + 命中后头顶黄油渍（淡黄像素）。

### 刀④ 投掷类真抛物弹道（重做 + 统一解算器）

v1.5 的 corn/melon/icemelon 复用西瓜**直线贴坡**分支；本刀抽出 v1.3 cabbage 的内联抛物解算为顶层公用函数 **`fireArcProjectile()`**（L1372），四种投掷类（cabbage/melon/icemelon/corn）统一走**真抛物**（`CABBAGE_VX=260 / CABBAGE_G=500`，零新常量）：

- 目标选择/提前量/发射点等几何与原 cabbage 内联逻辑**逐行等价迁移**（cabbage 等价性已由门控自证）。
- **★红线**：抛物积分判定改**字段存在性** `pr.vy!==undefined`（积分 L1546 / 越界 L1570），**禁用 type 白名单**——三处注入式弹体无 vy/g，白名单会致 NaN 崩。
- 绘制层加 `atan2(vy,vx)` 弹体倾角（抛物弧线观感）。
- 音效口径（主理人拍板）：四种投掷类统一**仅 `SFX.melonThrow`、零 `SFX.shoot`**（与 cabbage 同制）。

### 刀⑤ 测试模式沙盒化（新功能 + 存档保护）

`?test=1` 测试模式从「仅锁阳光」升级为**全卡池纯沙盒**：

- **卡池全开 12 种**（含西瓜/玉米/冰冻射手/冰冻西瓜等原本要通关/门槛才能拿的卡）+ **槽位拉满 10**（布局硬上限：卡栏 10 卡 992px < 1000，11 卡溢出）。
- **存档整体零写**：`saveMeta()` 首行 `if(testMode)return;` 一处收口覆盖全部 9 个存档键（points/slots/cards/deck/clears/diff_clears/unlocked/highscore/muted）——测试模式通关、刷分、静音**一律不落盘**，正常模式存档零污染。
- HUD 角标：`🧪 测试模式 · 阳光9999 · 全卡池 · 10槽`。
- **教训沉淀**：隔离类需求优先「整体零写」而非逐键守卫（逐键必漏——第5刀自证阶段即发现 `pvz_diff_clears` 漏守会永久吞掉难度门槛发卡）。
