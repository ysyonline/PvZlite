## 二、本版变更（相对 v2.3.9）

### 2.1 咬碑藤啃碑穿模消缺（用户反馈）

用户反馈「应该是一点点往下吃，碑一点点消失」。旧 v2.3.7 动画只移动咬碑藤主体，`drawWorldDecor` 的碑体不感知 `chewT`，导致啃食进度与碑体消失不同步（穿模）。

- **修复**：碑体随进度自碑顶 clip 裁剪逐渐消失 + 裁切缘咬痕齿线（阴影不裁）
  - `drawWorldDecor` 感知 `chewT`，clip 矩形 = 碑顶 + `_prog × 碑身总高`
  - 裁切缘画咬痕齿线（阴影不裁，保持立体感）
- **GRAVEBUSTER_GEOM** 增 `stoneH:34` / `stoneHArched:38` 共用碑身总高
- **裂纹钳制在剩余碑体内**：起点 `max(y+2+_down, 碑底-_gbH+_prog·_gbH)`，`_lenMax<8` 消失；碑型按 `findIndex i%2` 与 `drawWorldDecor` 同口径
- 真机视觉 `_v2310-gravebite-clip.js` **5/5**（旧 v2.3.9 源 2/5，T2/T3/T4 全红判别力 ✓）
- 探针 = 碑系中性灰 `|r-g|≤10 && b<r && 55<r<115`（⚠️ 写像素判据前先用 `_diag` 脚本采样真实色值——首版 `mx-mn<26` 把草皮全算灰判据失效）
- **探针兜底**：旧源缺新常量 → `geo()` undefined → `getImageData` 崩，`||34`/`||38` 兜底
