## 二、本版变更（相对 v2.3.7）

### 2.1 猫王召唤改正版机制（用户反馈）

原版查证（wiki.gg）：猫王僵尸（elvis）首召一次性铺满 4 只伴舞，之后伴舞死亡才逐只补召。

- **根因**：旧 `_first` 时间比较 bug——`summonT` 归零后 `0<12` 恒真，实际召唤间隔恒 3s 而非设计 9s
- **修复**：
  - 首召一次性铺满 `SUMMON_CAP=4`（本体列 + 左右相邻列）
  - 之后伴舞死亡才逐只补召（~3s/只，落本体列）
  - 满员不累计计时（正版不主动周期召唤）
  - 常量：`ELVIS_SUMMON_CAP` 6→4 / `COUNT` 3→1 / `INTERVAL` 9/7.5/6→3/2.6/2.2
  - 新增 `_firstSummoned` 字段并同步 harness probe 白名单
- 新增 **REG-ELVIS-02**（首召铺满 / 满员不补 / 死亡补 1 / 落位本体列）

### 2.2 小喷菇柄改矩形

- 旧柄：上窄下宽倒三角（顶 `_stW*0.75`、底 `_stW`）
- 修复：等宽矩形（上下均 `_stW`），观感更贴近原版

### 2.3 铁桶僵尸血量回调正版 1225

- 旧值 560（仅正版 46%），回调正版 **1225**
- 同步 README 僵尸表 / REG-ZOM-01 / harness 注入表
