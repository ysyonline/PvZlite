### 2.2 GRID 投影式采纳（Q-2=A · 口径升级）

- **裁决**：用户 2026-09-23 拍板 **采纳 GRID 网格修正式为 T>cd 域正式投影口径**。理由：全表最优（χ²=8.05 / R²=0.9875）+ **零拟合参数** + `T≤cd` 时严格退化为线性式（一式覆盖两域）。

### 2.3 R10 · 自然对局同格堆叠频率采样（`df4b0e1`）

| **P(≥1 \| n≥2)** | **1.0000**（52 次） | **1.0000**（177 次） | 0.5385（带状几何自洽） |

- **同格锁契约实战保持**：vCross=0 全种子（同排邻格零误溅）；8/8 全胜；自然溢杀率 0 / 0.68% / 0。
- **判别力自证**：v1.7 旧源 same=5,cross=2（带状跨格）vs 新源 same=17,cross=0（同格锁），两源弹着点数一致 ⇒ 读数差异归因规则而非管线伪影。
- 完整报告：`production/v19-r10-report.md`；脚本：`tests/playtests/v19-r10-natural-stacking.js`。

### 2.4 R11 · 溅射价值有效 DPS 口径（`72ecef6`）

双口径分析（A 反事实配对 + B 直中先行再分配），与 R10 同种子段：

| 臂 | utilization（上界） | clampRate（对照） |
|---|---|---|
| cabbage | **81.8%** | 0% |
| corn | **71.5%** | 0.68% |
| melon | **64.3%** | 0% |

- **核心结论**：溢杀 clamp 率≈0 与利用率落差的量化 = R7 画像预警「溢杀口径对战略冗余失明」**实锤**；32 对零结局翻转 ⇒ 肥阵下溅射不救局，价值 = **提速 + 补刀**（corn 中位快 1s，5/8 种子方向一致）。
- **口径建议**：后续叙事/调参引用溅射价值时用「有效 DPS（直中先行再分配）」，溢杀 clamp 仅作下界。
- 完整报告：`production/v19-r11-effective-dps-report.md`；脚本：`tests/playtests/v19-r11-effective-dps.js`。
