## §2 各项需求定义（据 D-1 定稿 + D-2 收敛；**合格线数值可直接埋进测量脚本**）

### R9 · 平衡口径鲁棒化（★ 底座，R9-a 先行）

**根因复盘**（D-2）：旧 `nerfModel`（v16-butter-balance.js L447-467）是代数投影 `min(1, p×T/cadence)`，隐含前提「每枚黄油独立贡献 T 时长」——cd(2.6)>T(2.5) 时恒真；T 改 3.0 后连发黄油在仍冻结时命中，浪费剩余 freezeT，投影 − 实测 = Σ(刷新时剩余 freezeT)/窗口。教训：**代数投影携带参数域前提，前提崩塌时口径静默失效**。

**R9-a · 权威口径**（直接事件账本，零代数假设）：
1. `freezeCoverage` = 冻结帧数/窗口（任何参数域成立）
2. `refreshWaste` = Σ(刷新事件时的剩余 freezeT)，与 naiveProjection 双轨上报、偏差逐 run 量化（保留 v16 legacy/resetEvents 双轨交叉校验）
3. `denialPx`（否认位移）= Σ(被剥夺的僵尸行程 px)，冻结=全额、chill=×0.6、自由=×1（状态机语义 L1626-1631）——对 T/cd/p 任意取值鲁棒，可被 R8 聚合成「每阳光否认位移」

**R9-b · 理论线标定**：候选式——泊松逼近 `1−(1−p)^(T/cd)` 与连续更新回报 `u=p/(cd+pT)`（单株投影残差各 −5.3/−5.4pp）。**标定通过 = 全锚点残差 ≤±2pp，锚点复测 ≥24 种子**。锚点全集：v1.6 单株 0.2583 / v1.7 单株 0.3119（M1）· 2 株 0.5598 / 3 株 0.609（M6）· 合成 0.7184（M5）。M6 的 `1−exp(−n·p·T/cd)` 须补拟合优度检验口径。**修正公式文档必须标 T≤cd / T>cd 两域分界**（D-1 增补 A 定案）。

**口径自检哨兵（P3，域判定双跑，D-1 增补 B-8 定稿）**：旧线性式 `p·n·T/cd` 在 **v1.6 域（T≤cd）应 PASS**、在 **v1.7 域（T>cd）必须 FAIL**——双域断言齐备哨兵判别力才完整；单域 FAIL 不足以证明判别力（可能在另一域也失效）。—— 把 v1.7 教训变成可执行回归。

**前提声明机制**（注释升级为机器校验）：脚本启动实测源码常量（强制开火读 p.cd、对假僵尸调 applyFreeze 读 T、读 splash/ratio）→ 动态判域：T≤cd ⇒ 加法投影有效；T>cd ⇒ 投影分支禁用并标记 `overlapWasteExpected=true`；实测与内置期望不符 ⇒ FAIL「源码漂移」。前提写进 `results.meta.preconditions`（数据），不写注释。`applyFreeze` 调用点计数（当前 1 处）同入前提。

**隐含前提**：①applyFreeze 是黄油唯一入口（溅射不调用，L1578 注释裁决）②freezeT 帧递减语义恒定 ③chill/freeze 并存状态机不变 ④顶层 function 沙箱桥可用（applyFreeze 若改 const 箭头函数桥即失效，须前置自检）⑤投影对照仅在 T≤cd 域启用。

### R7 · 溅射堆叠分布采样

**源码静态事实**（D-1/D-2 双重 Grep 核实，非待验证假设）：溅射仅同排（L1584 `z2.row===pr.row`）、同排一维带 |dx|<R（L1585）、依附直中（L1580）、直中目标排除（L1584）、无去重/无上限/无免疫帧/不触发再溅射（L1583-1589）⇒ **「独立掷定、无上限叠加」已由源码裁决，R7 测的是分布与浪费画像**。

三个关键推论（影响矩阵设计）：一弹只直中一只（L1595 break）⇒ 分布全来自溅射带；同排全部投手瞄准同一最前目标（L1374-1377）⇒ 弹着点几乎共点——**这是待验证假设**（判据见验收 ⑥）；投手布防列有下界（`fireArcProjectile` 要求 z.x > pos.x−10）。

**核心问题**：
- R7-Q1 每发溅射命中数分布（P0/1/2+）按「投掷物类型 × 密度档」分层是什么样？
- R7-Q2 小范围（30px）实际触发频率是否可感知？
- R7-Q3 溅射伤害浪费率（命中已死/将死僵尸比例）多大？

**采样矩阵**：植物类型 {cabbage×k / melon×k / corn×k / 混编} × 同排间距 {0 格 / 1 格 / 2 格} × k={2,3,4} × **每臂 ≥8 种子**（D-1 增补 B-4：直方图不敏感，窗口 90s 不变；项目种子段 6101+ 向后延展）。存活靶臂（hp×200）测纯分布 + 真实行程臂测溢杀。统计量：单目标每秒期望伤害±方差、直中/溅射占比、溅射命中率随间距衰减曲线、溢杀率、k=1 对照堆叠增益曲线。harness 沙箱推帧+固定种子（确定性），真机只留验收视觉抽查。

**溢杀口径（D-1 终稿口径补丁 · 口径冻结）**：**有效伤害 = min(max(当前hp, 0), 本弹伤害)，直中与溅射统一同式**；「当前 hp」= 逐弹结算瞬间读数（非窗口末）；下界 0 防溅射受害者负 hp 时序坑（L1594 死亡走下帧 filter）。meta 记 raw hp 差为附属字段，**溢杀率拆「直中溢杀 / 溅射溢杀」两栏**（直中溢杀与溅射调参无关、分栏防误读）。**适用域：溢杀指标仅真实行程臂定义上报；存活靶臂（hp×200 无死亡）clamp 恒等，维持 raw 分布。** 定案理由：①直中不同 clamp 会系统性偏袒大伤害卡、污染 tier 横向对比 ②有效 DPS 口径比名义 DPS 更严，未来若翻出「cabbage 反超 melon」信号即为真信号非伪影。

**⚠️ 溢杀时序坑**（D-2）：溅射受害者当帧不死（L1594 只结算直中者，死亡走下一帧 filter）⇒ 同帧可重复计伤、hp 可为负。记账按对象引用不按下标，死亡判定以 dead 标志为准。

**验收标准**：①四臂直方图+P(≥1) 落档 ②「大范围稳定吃 1 副目标」给 CONFIRM（P(≥1)≥0.8）/ REFUTE（≤0.4）/ 部分 判定 ③浪费率数值落档，**三档判读（画像型，非硬线）：≤10% 低 / 10–30% 中 / >30% 高——>30% 仅触发「登记建议项进优化池」，不返工**（增补 B-3）④脚本头部四行隐含前提声明 ⑤固定种子逐字节可复现 ⑥**弹着点共点假设判据：同臂 90s 窗口弹着点 x 极差 P95 ≤ 42px（=直中半宽）判成立；不成立则分布按弹着点分桶统计、禁混桶**（增补 B-1）。

### R8 · 多 corn 实战布防

**核心问题**：
- R8-Q1 前后错排（接力）vs 同排堆叠，覆盖率/击杀效率差多少？
- R8-Q2 混编收益：corn+melon / corn+icemelon 等组合相对纯 corn 是否显著（交互项）？
- R8-Q3 密度响应：常态/高压/极限三档下收益曲线如何走？

**口径**：
- 阵型参数化：`[{type,col,row}]` 描述符录入，随结果 JSON 落档（跨种子恒定、跨版本可比）。
- 三臂最小集：A 前后错排 / B 混编 / C 密度三档。僵尸构造：脚本注入错峰 x（受控首选，绕开波次 hp/spd 抖动 R(0.92,1.08)）＋ `api.newWave(n)` 真实波次臂（走 processSpawnQueue 含抖动）。**两口径结论若有出入属预期——分开上报、禁混合平均**（增补 A）。
- **双口径强制分开上报**：受控桶测（血量×200 永不死，控制占比纯）vs 真实行程（僵尸死亡会掩盖重叠浪费）——两者数字不可直接对比。
- **权威覆盖率口径 = 按目标均 `frozenFrac_target`（D-1 增补 B-5 定案）**，按行均仅附属上报——封死错排布防下行均稀释。
- **浪费率拆两指标（增补 B-6）**：浪费_刷新（同目标冻结中再中，与 R9 机制同构）与 浪费_错靶（黄油命中已冻结的他者目标）——分开统计、不合并不抵扣。
- 指标：控制侧（frozenFrac + union 占比，对齐 M6）+ 实战侧（TTK、突破深度、homeCount/timeout 三分类沿用 M6）+ 阳光效率（造价/击杀、造价/否认位移）+ 植物损耗。

**验收标准**：①臂矩阵全产出、**每臂种子 ≥10**（增补 B-7）、种子固定 ②每臂双指标齐全 ③「跨排接力是否优于同排堆叠」有数值结论，**形态差异判读带（按目标均）：<10pp 不敏感 / 10–25pp 中等 / >25pp 高敏感（推荐布防才有数据支撑价值）**（增补 B-7）④隐含前提四行声明齐全 ⑤若做推荐布防（Q-3），推荐须引用对比臂数据。
