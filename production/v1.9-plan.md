## §4 流程要求（沿用 v1.8 制度化成果）

1. **若本版动源码**：四门控全绿 —— 烟雾 29/29 · 全量 87/87（`run-all.js --all`）· 总线 56/56 · bench 五场景 PASS + **DC 结构量逐场景比对**（判级异常先看结构量，不动即噪声复跑）
2. **定版刀 = 版本标签通扫**（不止改 L49）：验收脚本 / 规格文档的**活默认值**（`PVZ_EXPECT_VER` 缺省等）须同步，改后**实测验证可运行**；历史记录保持原貌
3. **UI 类改动**：必须**真机截图 + 像素判据自证 + 旧源对照**（旧源必红），判据用主体色系
4. **提交前确认「磁盘行尾 == 仓库既有行尾」**（现已由 `.gitattributes` 兜底，不再依赖提交命令写法）
5. **验收脚本须通过可运行性门控**（契约漂移会因脚本跑不了而潜伏）
6. **无用户许可不 Write/Edit/commit**；已推送的不得 amend

## §8 R10/R11 执行结果摘要（2026-09-23）

### R10 · 自然对局同格堆叠频率采样（`tests/playtests/v19-r10-natural-stacking.js`，报告 `production/v19-r10-report.md`）

- **方法**：真实对局（`?test=1` 沙盒 + 真实种植路径 + 自然出怪）× 3 臂 × 8 种子（8101–8108），弹着点=spawnBurst orange 爆点，nStack 与溅射判定同刻同口径快照；判别力自证 = v1.7 旧源对照（统计法 60s+teleport+摆位 [800,816] + 伤害表分类器）。
- **结论**：①自然对局堆叠**机会率低**（cabbage 1.71% / corn 4.33% / melon 1.21%）；②**一旦堆叠，同格锁几何确定性完整保持**——P(≥1|n≥2)：cabbage 1.0（52 次）/ corn 1.0（177 次）/ melon 0.5385（与带状几何自洽）；③同格锁契约 vCross=0 全种子保持；④自然溢杀率 0 / 0.68% / 0；⑤8/8 全胜、wavesMedian=7。
- **判别力自证**：旧源 v1.7.0 `same=5,cross=2`（带状跨格溅射）vs 新源 `same=17,cross=0`（同格锁），两源弹着点数一致（30/30）。
- **附带披露**：R7 脚本 `v18-splash-distribution.js` 读 `e.w.kind`，在 prelude 09-22 `hitKind` 修复后**今日复跑必红**（潜在回归，已在 R10 报告 §5 登记，待后续版本修复）。

### R11 · 溅射价值有效 DPS 口径（`tests/playtests/v19-r11-effective-dps.js`，报告 `production/v19-r11-effective-dps-report.md`）

- **方法**：双口径——A 反事实配对（同种子 control 溅射禁用）+ B 直中先行再分配（有效率上界）；3 臂 × 8 种子，与 R10 同种子段。
- **结论**：①**溅射有效利用率（上界）**：cabbage 81.8% / corn 71.5% / melon 64.3%；②**溢杀 clamp 率≈0** 与利用率落差的量化 = R7 画像预警「溢杀口径对战略冗余失明」实锤；③**32 对零结局翻转**：肥阵下溅射不救局，价值 = 提速 + 补刀（corn 中位快 1s，5/8 种子方向一致）；④回归校验：前三臂与 R10 同种子 win 8/8 + wavesMedian=7 全复现。
- **口径建议**：后续叙事/调参引用溅射价值时用「有效 DPS（直中先行再分配）」口径，溢杀 clamp 仅作下界。
