3. **超出施工规格的一处改动（请 QA/用户留意）**：**右侧檐沟顶随平台抬升到 `GRID_Y−H`（L1545–1549，roof-gated）**。规格 §2.E 表未列此项，但美术权威 §3-2 檐沟铺满 `y∈[GT(20), BY(600)]`；不抬升会在平台右上（x∈[865,955]×y∈[20,80]）露 60px 天空缝。已 roof-gate（老关恒 `GRID_Y` ⇒ 逐字节等价）。**如判定越界可单点回退该 2 行。**
4. **完全未变的既有瑕疵（非本轮引入）**：画布右缘 `x∈[955,1000]`、`y∈[90,600]` 露出 CSS 绿底——**改动前后截图均存在**（`road` 宽 `ROAD_W=90` 仅覆盖 865–955，全关卡既有）。本轮「不露绿底」目标指**屋面底边停 y=600**（已达成），右缘绿条属既有问题，未在本轮范围内擅改。**建议单列 issue。**
5. **bench p50 +46%**：见 §5，仍在半预算内。
6. **`ROOF_SLOPE=0.18` 保留未删**（加「C2 弃用」注）：C2 绘制口径不引用该常量；如需彻底清理可后续删除（回退更干净，spec §7-5 归实现期定夺）。
