## §1 现状分析

### 1.1 动画全貌

| 属性 | 当前值 | 代码位置 |
|---|---|---|
| 状态管理 | `giftAnim = { active, t, card }` | L885 |
| 动画时长常量 | `GIFT_OPEN_TIME = 1.2s`, `GIFT_REVEAL_TIME = 1.8s` | L886–887 |
| 时间推进 | `giftAnim.t += dt`（仅在 `state === 'end'` 时） | L1281 |
| 绘制入口 | `drawEnd()` 内嵌，位于「通关！」标题下方的动画区（y=290~460） | L4167 |
| 触发来源 | ① CARD_AWARD 发卡（L2552）；② DIFF_AWARD 发卡（L2568） | — |
| 复位 | 新对局开始时 `giftAnim = { active: false, t: 0, card: null }` | L1756 |
| 盒体尺寸 | 140 × 120 px，中心 (cx, 355) | L4171–4172 |
| 渲染方式 | Canvas 2D 即时模式（无纹理，纯几何 + fillRect/ellipse/arc） | — |

### 1.2 逐帧拆解：当前实现

#### 阶段 A：闭合态（`t < 0.6s`）

| 元素 | 绘制方式 | 颜色 |
|---|---|---|
| 底座阴影 | `ellipse(boxCX, boxCY+boxH/2+6, boxW/2+10, 10)` | `rgba(0,0,0,0.35)` |
| 盒子底座 | `fillRect` 140×120 | `#8b5e2a` |
| 底座描边 | `strokeRect` 3px | `#5a3a1a` |
| 盖子 | `fillRect` 148×20，较底座左右各宽 4px | `#9b6e3a` |
| 盖子描边 | `strokeRect` 2px | `#5a3a1a` |
| 十字绑带 | 垂直 + 水平 `moveTo/lineTo`，4px | `#ffce3a` |
| 蝴蝶结（三片） | 左右 `ellipse`(12×6) + 中心 `arc`(r=7) | `#ffce3a` |
| "打开中..."文字 | 14px YaHei，t>0.2 渐显 | `rgba(255,255,255,...)` |

**呼吸动画**：`const pulse = 1 + Math.sin(t * 5) * 0.03`（L4204）— **计算了但未应用到 `ctx.scale`/`ctx.translate`，实际无效果**。

#### 阶段 B：开盖后（`t ≥ 0.6s`）

| 子阶段 | 时间 | 元素 | 缓动 |
|---|---|---|---|
| 盒子底座（保留） | 全程 | `fillRect` + 横向绑带（半透明 `#ffce3a40`） | — |
| 盖子飞起 | t=0.6→0.9（0.3s） | 沿弧线：dx=+30×ease, dy=-80×ease，旋转 0.6rad | `easeOutCubic` |
| 开盖闪光 | t=0.6→0.85（0.25s） | 从中心扩展的径向圆，alpha 0.5→0 | `rgba(255,230,120, ...)` |
| 粒子飞散 | t=0.6→0.9（0.3s，12 粒错开 0.05s/粒） | 径向 12 方向，半径 80px，alpha 递减 | `rgba(255,220,80, ...)` |
| 植物生长 | t=0.6→0.9（0.3s） | scale 0.3→1.0 + y 从盒内浮起 20px | `easeOut`（0.3s 后定格） |
| 植物名称 | t>1.2→1.5 | 名称（22px 金色） + "新植物解锁！"（14px 白色）渐显 | alpha 淡入 |

**植物卡片渲染**：调用 `drawCardFace(card, 0, -30, 120, 80)` — 即原始卡片面的 120×80 放大版（正常卡片 88×78）。

#### 阶段 C：展示态（`t > 1.2s`）

植物定格、名称可见。动画停止演进，等待用户点击「下一关」或「返回选关」。

**注意**：`GIFT_OPEN_TIME=1.2` / `GIFT_REVEAL_TIME=1.8` 常量定义了但绘图中实际未使用——绘图用的是硬编码 `lidPhase=0.6` / `revealPhase=1.2`。

### 1.3 关键发现

| # | 发现 | 严重程度 |
|---|---|---|
| F1 | **呼吸动画失效**：`pulse` 变量（L4204）计算了但 `ctx.scale` 未调用，盒子完全静止 | 🔴 功能缺陷 |
| F2 | **常量与硬编码不一致**：`GIFT_OPEN_TIME=1.2`，但 lidPhase 硬编码为 0.6——两套时间体系并存 | 🟡 维护隐患 |
| F3 | **无音效联动**：盖子飞起、植物弹出均无对应 SFX 调用（`SFX.win()` 在通关时触发一次，不与动画同步） | 🟡 体验欠完整 |
| F4 | **盖子无限滑行**：盖子停在空中固定位置（dx=30, dy=-80），无落地/弹跳，像一个飘走的气球 | 🟡 视觉打磨 |
| F5 | **粒子过于朴素**：仅 12 粒小圆点（r=3），单色，无拖尾/闪烁/形状变化 | 🟡 视觉打磨 |
| F6 | **植物卡片缩放不当**：`drawCardFace(card, 0, -30, 120, 80)` 将 88×78 的卡片等比放大到 120×80，部分卡面（如 corn 的细粒点阵）在放大后显得粗糙 | 🟡 视觉打磨 |
| F7 | **无 exit 动画**：用户点击下一关/返回后动画立即切断，盒子/植物瞬间消失 | 🟢 可接受 |
| F8 | **色板未完全对齐美术圣经**：`#8b5e2a`（盒子） vs `--wood-mid: #8b6528` 有细微偏差 | 🟢 可接受 |
| F9 | **"正在解锁..." / "打开中..." 文字过于廉价**：缺少自定义字体或描边阴影，与结算屏其他部分视觉层级不匹配 | 🟢 低优先级 |
| F10 | **仅支持有卡奖励的关卡**：无奖励卡结算屏只显示「✧ 恭喜通关！✧」无动画 | 🟢 设计意图 |

### 1.4 缺陷清单（按优先级排序）

| ID | 严重度 | 位置 | 描述 | 建议 |
|---|---|---|---|---|
| B-01 | 🔴 P0 | L4204 | `pulse` 计算后未应用到变换矩阵，闭合态盒子无呼吸动画 | 在绘制盒子底座前加 `ctx.scale(pulse, pulse)` 并 restore |
| B-02 | 🟡 P1 | L4178–4179 vs L886–887 | 硬编码 `lidPhase=0.6` / `revealPhase=1.2` 与常量 `GIFT_OPEN_TIME=1.2` / `GIFT_REVEAL_TIME=1.8` 无引用关系 | 统一引用常量，`lidPhase` 改为 `GIFT_OPEN_TIME * 0.5` |
| B-03 | 🟡 P1 | L4225–4241 | 盖子飞起后停在空中无弹跳/落地，视觉效果不完整 | 加 0.5s 弹跳阶段（see §4.1） |
| B-04 | 🟡 P1 | L4257–4266 | 12 粒小圆点粒子无形状变化、无拖尾、无闪烁 | 增补星星形粒子 + 颜色渐变（see §5.2） |
| B-05 | 🟡 P1 | 全动画 | 无音效联动（开盖声 / 弹出声 / 名称揭示声） | 在 lidPhase 时刻调用 `SFX.unlock()`（需阮和鸣提供音效定义） |
| B-06 | 🟢 P2 | L4271 | `drawCardFace(card, 0, -30, 120, 80)` 放大倍率不合理 | 调整为 100×72（等比缩放 88:78 ≈ 100:72），或直接绘制 plant world 版 |
| B-07 | 🟢 P2 | L4288–4291 | 「正在解锁...」 / 「打开中...」文字缺少装饰 | 加 1px 黑色投影或微弱 outline |
| B-08 | 🟢 P3 | L4176 | 阴影椭圆与美术圣经中其他 UI 阴影（如卡片阴影）风格不一致 | 统一阴影方向（右下偏移 4px+4px）和透明度 |

## §2 目标视觉体验

### 2.1 体验锚点（一句话）

> **"礼盒颤抖 → 盖子弹飞 → 金光迸裂 → 植物从盒中跃出 —— 3 秒的 mini 庆典，让'获得新植物'成为玩家最期待的时刻。"**

### 2.2 风格参照

| 参照来源 | 借用元素 |
|---|---|
| 马里奥 Odyssey 月亮收集 | 物品从容器中弹出 + 旋转 + 闪光环 |
| 塞尔达 BotW 宝箱开箱 | 盖子缓慢打开 → 金光溢出 → 物品浮现（慢节奏庄严感，本作取其「金光从缝隙漏出」阶段） |
| PvZ 原版 1.0 卡片解锁 | 卡片从信封中抽出 + 金色徽章旋转（本作取其「卡片框架 + 名称浮现」模式） |
| 本作美术圣经（art-handoff.md） | 全部色彩、缓动函数、粒子规格均须对齐 |

### 3.2 材质与形状

| 元素 | 形状语言 | 材质感 |
|---|---|---|
| 盒子底座 | 纯矩形 `fillRect`，圆角 4px（`roundRect` 或手动 corner） | 哑光木质感（单色填充，无渐变） |
| 盖子 | 矩形 148×20，圆角 4px（顶边），平底 | 略亮于底座，形成顶面受光暗示 |
| 绑带 | 4px 宽线条，十字交叉 | 丝绸光泽（纯色 `--sun-gold`，无渐变） |
| 蝴蝶结 | 两侧椭圆 12×6 + 中心圆 r=7 | 与绑带同色、同质感 |
| 盖子弹飞后残留绑带 | 仅横向绑带，半透明（`#ffce3a40`） | 暗示绑带被扯断残留 |
| 粒子 | 圆形（小）+ 四角星（大）+ 三角碎屑 | 硬边（无模糊），卡通粒子语言 |

**几何约束**：
- 盒子必须画在结算屏「通关！」标题之下、分数行之上（当前 y=290~460，不需要挪）
- 盒子中心 `cx = canvas.width / 2`（500px），垂直中心 `boxCY = 355`
- 盒子宽 140px，高 120px（不变）

## §4 动画时间轴（重新设计）

### 4.1 阶段划分

```
总时长：约 3.0 秒（从盒子出现到植物名称完全可见）

 0.0s          0.6s     0.85s    1.0s     1.5s      2.0s                 3.0s+
  |-----A------|--B--|----C----|----D----|-----E------|------F(展示态)-----→
  闭合呼吸      开盖   植物跃出   粒子高潮   名称揭示     无限等待用户交互
```

| 阶段 | 时间窗口 | 名称 | 关键动作 |
|---|---|---|---|
| **A** | 0.00–0.60s | **闭合呼吸** | 盒子出现即开始微微呼吸（scale 1.00↔1.03, 周期 0.8s）。"打开中..." 在 0.2s 淡入。盒子整体从 y+20 轻微弹入（0→0.25s）。 |
| **B** | 0.60–0.85s | **开盖爆发** | 盖子弹飞：沿弧线 dx=+35, dy=-90，旋转 0.7rad，缓动 `easeOutBack`。同时：盒内金光从缝隙溢出→全开瞬间白色闪光环扩散。 |
| **C** | 0.85–1.10s | **植物跃出** | 植物从盒内升起：scale 0.3→1.1→1.0（过冲回弹），y 从盒内 +10px→盒口上方 -30px。粒子第一波（12 粒星星形，径向爆散）。 |
| **D** | 1.10–1.50s | **粒子高潮** | 粒子第二波（8 粒大星星 + 16 粒小圆点），速度更快、范围更大。紫色/金色闪烁。植物轮廓光脉冲 1 次。盖子落地弹跳（y 从 -90 回弹到 -70→-85→-78 定）。 |
| **E** | 1.50–2.00s | **名称揭示** | 植物名称（22px, gold）从 alpha 0→1 淡入，伴随轻微 scale pop（1.0→1.08→1.0）。"新植物解锁！"（14px, white 75%）略延迟 0.15s 淡入。 |
| **F** | 2.00s+ | **展示态** | 植物定格 + 微呼吸（scale ±2%，周期 2s）。粒子逐渐消散（alpha → 0 over 1s）。等待用户交互。 |

### 4.2 缓动函数分配

所有缓动函数须对齐 `design/art-handoff.md` §B 的 `Easing` 对象（已在代码 L1146–1158 实现）。

| 动作 | 缓动 | 理由 |
|---|---|---|
| 盒子弹入 | `easeOutBack` | 有「放置」的重量感 |
| 盒子呼吸 | `sin`（非 Easing） | 循环动画 |
| 盖子弹飞 | `easeOutBack` | 弹性过冲 = "弹飞"的弹簧感 |
| 盖子落地弹跳 | `easeOutBounce` | 物理真实感 |
| 植物生长（主阶段） | `easeOutBack` | 轻微过冲 → 弹性质感 |
| 植物生长（回弹段） | `easeOutCubic` | 从过冲回归稳定 |
| 粒子位移 | `linear` / `easeOut` | 线性飞出 + 减速 |
| 名称揭示 scale pop | `easeOutBack` | 与植物弹出呼应 |
| 闪光环扩散 | `easeOutCubic` | 快速衰减 |

### 4.3 关键帧数值表

#### 盒子整体（A 阶段弹入）

```
t(s):    0.00   0.10   0.25   0.60
y_off:  +20     +12     0      0      (easeOutBack, offset from final boxCY)
scale:   0.85   0.95   1.00   1.00   (同步弹入)
```

#### 盒子呼吸（A 阶段全程）

```
呼吸 scale = 1.00 + sin(t * PI * 2 / 0.8) * 0.03
即：周期 0.8s，振幅 ±3%
```

#### 盖子飞起（B 阶段）

```
t_rel(s):  0.00   0.15   0.25   0.25+（落地前悬停）
dx(px):      0     18     35     35
dy(px):      0    -55    -90    -90
rotation:    0    0.35   0.70   0.70
缓动：easeOutBack（弹性过冲系数 = 1.7）
```

#### 盖子落地弹跳（D 阶段）

```
t_rel(s):  0.00   0.08   0.18   0.28   0.35
dy(px):    -90    -70    -85    -78    -78
缓动：easeOutBounce
```

#### 植物生长（C 阶段）

```
t_rel(s):  0.00   0.12   0.20   0.25   0.30
scale:     0.30   0.85   1.10   0.95   1.00
y_off(px): +10     -5    -30    -26    -28
alpha:     0.0    0.6    1.0    1.0    1.0
主缓动：easeOutBack（0→0.20s），回弹：easeOutCubic（0.20→0.30s）
```

#### 名称揭示（E 阶段）

```
t_rel(s):  0.00   0.20   0.30   0.50
nameAlpha:   0     0.7    1.0    1.0    (easeOut)
nameScale:  1.00   1.08   1.00   1.00   (easeOutBack)
subAlpha:    0      0      0.6    1.0    (延迟 0.2s，easeOut)
```

## §5 粒子与特效规格

### 5.1 开盖闪光（B 阶段，0.60–0.85s）

```
类型：径向扩展圆形（从盒中心扩散）
层1（内圈·白光）：t_rel 0→0.12s, r: 20→140px, alpha: 0.8→0, color: #fffbe6
层2（外圈·金光）：t_rel 0.05→0.25s, r: 40→250px, alpha: 0.5→0, color: #ffd54a
缓动：easeOutCubic
```

### 5.2 星星/彩纸粒子

#### 第一波（C 阶段，0.85–1.30s）：12 粒「四角星」

| 属性 | 值 |
|---|---|
| 形状 | 四角星（通过 `sin/cos` 在 `r` 处交替缩进绘制，形似 ✦） |
| 数量 | 12 粒 |
| 发射方式 | 从盒口中心（boxCX, boxCY-30）径向发射，12 等分方向 |
| 速度 | 径向 120~200 px/s |
| 初始 scale | 0.4 |
| 终态 scale | 1.0（生长）+ 旋转 0→180° |
| 颜色 | `#ffce3a`(×4), `#ffd54a`(×4), `#ffecb3`(×2), `#c9a34a`(×2) |
| 生命周期 | 0.45s/粒（每粒延时 0.04s 发射），alpha: 1→0（最后 0.2s 衰减） |
| 缓动 | 位移 `easeOut`，缩放 `easeOutBack` |

#### 第二波（D 阶段，1.10–1.60s）：8 粒「大星星」+ 16 粒「小圆点」

| 属性 | 大星星 | 小圆点 |
|---|---|---|
| 形状 | 四角星（同上） | 圆形 r=2~4px |
| 数量 | 8 粒 | 16 粒 |
| 发射方向 | 上半球（-60° ~ +60°，即指向上方为主） | 全向随机 |
| 速度 | 80~150 px/s | 60~200 px/s |
| 颜色 | 金色系 + 1 粒紫色 `#a0446a`（呼应 mine 色板，见 art-handoff L78） | 金色系 |
| 生命周期 | 0.5s/粒 | 0.35~0.55s/粒（随机） |

#### 持续浮动粒子（展示态 F，2.0s+）

在植物周围缓慢上浮 4~6 粒微小光点（r=1.5px, alpha=0.3~0.6），速度 15~25 px/s，y 方向向上，x 方向微漂移。生命周期 2s，循环生成。为展示态增加「活着」的感觉。

### 5.3 植物轮廓光（C→D 阶段）

植物 scale 到 1.0 的瞬间（t≈1.05s），以植物中心为圆心扩散一圈白色光环：

```
r: 30→80px
alpha: 0.6→0
duration: 0.25s
color: rgba(255,255,255, ...)
缓动：easeOutCubic
```

### 5.4 盒内光柱（B→C 阶段）

从盒口向上射出锥形光柱（半透明金色三角形/梯形）：

```
顶点1: (boxCX-50, boxCY-60)   顶点2: (boxCX+50, boxCY-60)
底边:  盒口宽度 boxW
颜色: rgba(255,230,140, 0.5 → 0.0)  从盒口向上渐变透明
alpha: 0.7→0 (0.60~1.00s, 与植物生长同步衰减)
```

建议用 `ctx.createLinearGradient` 从盒口（y=boxCY-60）到光柱顶端（y=boxCY-120）。
