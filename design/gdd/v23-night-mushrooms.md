## §1 现状评估

### 1.1 现有植物体系空缺

现有 15 种植物（v2.2.8）职能分布：

| 职能 | 植物 | 数量 |
|---|---|---|
| 经济 | sunflower | 1 |
| 直线输出 | pea / double / snowpea | 3 |
| 抛物输出 | cabbage / corn / melon / icemelon | 4 |
| 防御 | nut | 1 |
| 地形载体 | lilypad / planter | 2 |
| 一次性秒杀 | mine / squash / pepper / cherry | 4 |

**核心空缺**（对比原版 PvZ 夜晚关卡）：

1. **无「夜行」植物概念**——当前夜晚（1-6~1-10 / 2-3~2-10）玩法与白天完全一致，仅换滤镜与草坪色。原版夜晚的灵魂是「蘑菇白天睡、夜晚醒」，迫使玩家夜晚换用蘑菇体系，形成世界 2 的玩法转折。
2. **无零成本炮灰**——原版小喷菇 0 阳光是夜晚「缺阳光却要拖时间」的关键解；本作缺阳光时只能干等。
3. **无穿透型输出**——原版大喷菇穿透是克制报纸僵尸/铁门僵尸（世界 2 新增）的标配。
4. **无反制僵尸的手段**——原版魅惑菇是「以敌制敌」的策略卡，本作完全空白。
5. **夜晚经济单一**——当前夜晚只有向日葵（且刚修复为 24s 更慢），缺乏「低门槛夜行产阳光」的替代。

### 1.2 与 v2.2.8 的衔接

v2.2.8 刚落地「夜晚天空不掉阳光 + 向日葵夜晚 24s」，**夜晚阳光进一步收紧**。四种蘑菇正是对应这个收紧节奏的「夜间专属解法」——不改变 v2.2.8 的既有参数，而是新增夜间经济/输出/控场选项。

## §2 夜行机制（nocturnal）总设计

### 2.1 核心规则

> **蘑菇类植物在白天（`level.time === 'day'`）进入「沉睡」状态：不产出、不攻击、不可触发；夜晚（`night`）与浓雾（`fog`）清醒。**

| 状态 | 白天（day） | 夜晚（night） | 浓雾（fog） |
|---|---|---|---|
| 阳光菇 | 沉睡，不产阳光 | 清醒，正常产阳光 | 清醒，正常产阳光 |
| 小喷菇 | 沉睡，不攻击 | 清醒，正常攻击 | 清醒，正常攻击 |
| 大喷菇 | 沉睡，不攻击 | 清醒，正常攻击 | 清醒，正常攻击 |
| 魅惑菇 | 沉睡，不可魅惑 | 清醒，可魅惑 | 清醒，可魅惑 |

### 2.2 沉睡状态的判定与表现

- **判定**：`_isNight = level.time === 'night' || level.time === 'fog'`（源码已有此口径，见 `drawPlant` L2801 一带的 `_isNight`）。
- **字段**：新增植物字段 `asleep: boolean`（运行时派生，不需落盘），或直接由 `level.time` 即时判定（推荐：**即时判定，不新增状态字段**，降低 probe 快照改动面）。
- **表现**：沉睡时绘制半闭眼/耷拉姿态（视觉层），卡面右下角标注「☾ 夜行」提示。
- **守卫位置**：updatePlant 的向日葵/攻击/触发分支各自开头加 `if (isNocturnal(type) && !_isNight) return/skip`。

### 2.3 白天强制唤醒（暂缓，列为 v3.x）

原版白天可用「咖啡豆（Coffee Bean）」唤醒蘑菇。**本作 v2.3 不引入咖啡豆**，白天蘑菇纯沉睡——避免新增植物 + 平衡复杂度。此缺口记为后续可选需求。

## §3 逐植物规格

### 3.1 阳光菇（sunshroom）· 夜晚经济主力

| 字段 | 值 | 说明 |
|---|---|---|
| type | `sunshroom` | 新增卡 |
| name | 阳光菇 | — |
| cost | **25** | 原版 25；比向日葵(50)低一半，弥补夜晚缺阳光 |
| 种植 cd | **7.5s** | 原版 7.5 |
| dur（耐久） | **300** | 原版 300 |
| 首产 | **6s**（夜晚） | 原版「夜晚 6s 后首产小阳光」 |
| 周期 | **24s** | 与向日葵夜晚 24s 对齐 |
| 产量 | 幼体 **15** / 成体 **25** | 原版：幼体小阳光(15)、成体大阳光(25) |
| 成长 | **120s** 后成体 | 原版 120s；成长**不重置**产阳光计时 |
| 夜行 | 白天沉睡 | §2 |

**设计要点**：
1. 幼体阶段产出 15 阳光（小阳光），种植 120s 后成体，此后产出 25（大阳光）——与向日葵形成「前期廉价回本慢、后期追平」的节奏差异。
2. 成长计时与产阳光计时**独立**（原版关键设定：成体后不重置产阳光周期）。
3. 绘制：小号灰紫菇盖，成体后菇盖变大 + 金黄环。

**产出价值对照**（夜晚 24s 间隔下）：
- 向日葵：50 阳光投入 → 25/24s
- 阳光菇：25 阳光投入 → 15/24s（前 120s）→ 25/24s（成体后）

### 3.2 小喷菇（puffshroom）· 零成本炮灰

| 字段 | 值 | 说明 |
|---|---|---|
| type | `puffshroom` | 新增卡 |
| name | 小喷菇 | — |
| cost | **0** | 原版 0——夜晚「缺阳光拖时间」关键解 |
| 种植 cd | **7.5s** | 原版 7.5 |
| dur（耐久） | **300** | 原版 300 |
| 攻击 | **20 伤害 / 1.4s** | 原版 20/1.4s |
| 射程 | **3 格** | 原版 3 格（短程） |
| 弹道 | 直线孢子（同 pea 直线，非抛物） | 无溅射 |
| 夜行 | 白天沉睡 | §2 |

**设计要点**：
1. **零成本**是核心卖点——夜晚开局无阳光时先铺小喷菇拖时间等阳光菇产出。
2. 短射程 3 格是平衡约束：便宜但必须贴脸，僵尸走近才能打，鼓励玩家在近端布防。
3. 弹体可复用现有直线弹管线（`projectiles.push` type 加 `'puff'`，dmg 20），绘制为紫色小孢子。

### 3.3 大喷菇（fumeshroom）· 穿透输出

| 字段 | 值 | 说明 |
|---|---|---|
| type | `fumeshroom` | 新增卡 |
| name | 大喷菇 | — |
| cost | **75** | 原版 75 |
| 种植 cd | **7.5s** | 原版 7.5 |
| dur（耐久） | **300** | 原版 300 |
| 攻击 | **20 伤害 / 1.4s** | 原版 20/1.4s（注意：重制版有标 35，取**原版 20** 为准） |
| 射程 | **4 格** | 原版 4 格 |
| 弹道 | 直线烟雾，**穿透本行全部僵尸** | 无视护具（报纸/铁门/梯子） |
| 夜行 | 白天沉睡 | §2 |

**设计要点**：
1. **穿透**是核心差异——一发烟雾对本行射程内**所有**僵尸同时造成 20 伤害，是本作第一个「群伤直线」输出。
2. 克制目标：世界 2 新增的报纸僵尸/铁门僵尸（护具不影响穿透命中）。
3. 实现建议：烟雾弹体标记 `pierce: true`，命中判定循环本行全部僵尸（区别于现有单目标命中即消失），或在 updateProjectiles 命中分支新增「穿透」路径。
4. 绘制：紫色大菇盖 + 灰色烟雾云（半透明，覆盖射程区间）。

### 3.4 魅惑菇（hypnoshroom）· 以敌制敌

| 字段 | 值 | 说明 |
|---|---|---|
| type | `hypnoshroom` | 新增卡 |
| name | 魅惑菇 | — |
| cost | **75** | 原版 75 |
| 种植 cd | **30s** | 原版 30（慢，策略卡） |
| dur（耐久） | **300** | 原版 300 |
| 效果 | 被僵尸**啃食**时，魅惑该僵尸 | 僵尸转为玩家阵营，向右行走并攻击其他僵尸 |
| 免疫 | 巨人 / 冰车 / 投石车**无效** | 原版豁免名单 |
| 夜行 | 白天沉睡 | §2 |

**设计要点**：
1. **触发方式 = 被啃食**——不是主动、也不是踩中，而是「僵尸啃到它时」触发（区别于地雷/航椒的「踩中」）。这要求 updateZombies 啃食目标判定里识别魅惑菇。
2. **魅惑状态机**（新增僵尸字段）：
   - `z.hypno = true`：被魅惑僵尸向右行走（`spd` 取反或正负标记），攻击**敌方**僵尸。
   - 被魅惑僵尸与其他僵尸互相伤害判定需新增。
   - 魅惑后魅惑菇自身 `_dying = true` 消失。
3. **免疫名单**：巨人（Gargantuar，本作若未引入则暂空）、冰车、投石车——本作 v2.3 若未实装这些僵尸，豁免名单暂记位，避免后续硬编码。
4. 绘制：紫红小菇 + 螺旋纹（催眠暗示）。

## §4 僵尸阵营交互（魅惑菇衍生）

本作现有僵尸无「阵营」概念，魅惑菇是首个引入「敌我阵营」的植物。**最小改动方案**：

1. 僵尸对象新增字段 `hypno: boolean`（默认 false，probe 快照白名单需同步）。
2. 被魅惑僵尸：
   - `spd` 反向（向右走）；
   - 攻击目标从「植物」切换为「敌方僵尸」——需在 updateZombies 里对被魅惑僵尸单独走「啃敌方僵尸」分支；
   - 与敌方僵尸的碰撞/互相伤害判定（可简化为：被魅惑僵尸每 0.5s 对相邻敌方僵尸造成一次啃食伤害，对齐僵尸啃植物 65/s 的口径或自定义）。
3. 死亡判定：被魅惑僵尸可被敌方僵尸反杀，死亡后不再计分或计玩家分（建议：被魅惑僵尸击杀敌方僵尸**计入玩家击杀分**，被反杀不计分）。

> ⚠️ 本节为 v2.3 复杂度最高点，**建议拆为独立任务单元**（魅惑状态机），与其余三蘑菇解耦施工。
