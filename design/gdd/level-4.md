## §1 概述

### 1.1 本关定位

| | L2 黄昏草坪 | L3 月夜草坪 | **L4 泳池（本关）** |
|---|---|---|---|
| 教学定位 | 进阶关：引入移速威胁（fast） | 毕业关：引入护甲威胁（bucket）与多波高潮节奏 | **进阶二幕：引入空间轴（水域 = 可部署面缩减 40%）** |
| 参考原版 | PvZ 1-2 | PvZ 1-3/1-4 段位 | PvZ 3-x 泳池段位（中两行水域 + 睡莲浮床） |
| 僵尸种类 | normal、cone、fast | 4 种全员 | **复用 4 种全员（零新增、零变体）** |
| 波次 / 总量 | 6 波 / 24 只 | 7 波 / 33 只 | **8 波 / 38 只** |
| 大波（带预警横幅）数 | 2（W4/W6） | 3（W3/W5/W7） | **3（W3/W6/W8）** |
| 场地 | 9×5 全陆地 | 9×5 全陆地 | **9×5，中两行水域（0-indexed 第 1/3 行），水上种植必须先铺睡莲** |

### 1.2 目标体验

一句话：**「同一套旧知识，现在要在一张贵 25 阳光一格的棋盘上重新排版」**。

- 玩家带着 L3 通关的全部阵容记忆进入 L4，W1–W2 感觉"和以前开局差不多"（刻意设计，见 §5.2）；
- 随后第一个随机落进水行的僵尸教会玩家本关唯一的新规则：**水里不能直接种**——先垫 25，再种植物；这一课无法被跳过，因为水行僵尸必经水行，水行不设防必被破线；
- 玩家将自发收敛到本关的核心策略：**陆地（3 行，无税）留给经济与肉盾，水域（2 行，有税）交给火力前线**——空间轴的难度不来自新操作，而来自每一次部署前多问一句"这格要不要垫"；
- W6 铁桶回归开启第二幕，W8 终波以**双铁桶压轴**（单波 2480 hp，系列之最）收束全关。

### 1.3 与 L1–L3 的关系

- **继承**：全部规则机制（阳光经济、卡片冷却、清场门槛、大波预警、25s 兜底）零改动；植物卡 6 张全保留（新增第 7 张睡莲）；START_SN / LEVELS 数据结构完全同构，仅新增一个键 + 水域行常量。
- **递进**：L1 血量轴 → L2 +速度轴 → L3 +护甲三轴 → **L4 引入空间轴（可部署面 -40%，水上部署需 25/格的睡莲税）**。僵尸威胁维度已在 L3 满配（4 种全员），L4 不再加僵尸维度，难度增量全部由空间轴支付；作为补偿，数量斜率与时长斜率同步放缓（§9.1）。
- **解锁链**：L3 通关 → L4（`unlockedLevel` 自动支持，L106–L119）；`?level=4` 直进由既有上界校验自动扩展（上界 = `LEVELS` 键数 3→4，无需改校验代码）。

## §2 玩法目标与设计支柱

### 2.1 本关考验玩家什么新能力

| 新能力 | 触发场景 | 支撑机制（全部已存在，唯一新实体为睡莲卡） |
|---|---|---|
| **水域部署规划** | 随机行刷怪下，期望 40% 僵尸走水行（38×2/5 ≈ 15.2 只） | 睡莲（25 费 / 建议 5s CD）：水行种植前置；W3 前必须完成水行首轮投资 |
| **陆地/水域分工** | 陆地 3 行无税、水域 2 行有税 | 向日葵经济天然向陆地集中（水行种葵 = 白缴 25 税还占火力位） |
| **贵格火力管理** | W6–W8 铁桶若落水行，双发需垫（200+25=225，全场最贵单格投资） | 双发/西瓜集火 + 坚果拖延，全部 L3 已学手段 |
| **8 波资源规划** | 总时长 ≈4 分钟，系列最长 | 葵 5–6 张的后期经济线（推导见 §5.3） |

### 2.2 设计支柱（4 条，本 GDD 所有数值决策的裁判标准）

1. **「水域是预算问题，不是操作问题」** —— 空间轴的难度**全部**通过阳光税（睡莲 25/格）与部署规划表达，不改任何机制数值、不给水行任何特殊行进/受击规则。任何"水行僵尸该游快点/慢点"的念头都违背本支柱。
2. **「先学水，再遇全甲」** —— 两幕结构：W1–W5 用 L1–L3 已认识的威胁（无 bucket）教水行部署；W6–W8 才放回铁桶与全家福。新的空间规则永远在旧威胁框架内学习（继承 L3 支柱 2 的"可读性"精神——本关"必须可读的新东西"是水格规则本身，它在第一只僵尸到来前就由水面渲染 + 卡片栏第 7 张完成告知）。
3. **「水陆分工」** —— 引导（不强制）的经济分工：陆地 = 经济与肉盾（无税），水域 = 火力前线（有税）。设计上通过开局软压力（W1/W2 与 L3 同构）保证玩家**有条件**把经济留在陆地；水行种葵不禁止，但 25 税 + 占火力位会让玩家自发放弃。
4. **「构成复用，空间唯一」** —— W1–W7 的僵尸构成大量复用 L3 同位波（§9.2），**这是刻意的**：本关的认知预算全部花在水域规则上；若构成也翻新，就是 L3 支柱 3 警告过的认知过载。新鲜感唯一来源 = 空间轴 + 双桶终波。

### 2.3 玩家心理映射（SDT）

| 心理需求 | 本关供给 |
|---|---|
| 胜任感 | W8 双桶压轴击杀（每只 +150 分）= 系列最高单波奖励；"我能在更贵的棋盘上打出 L3 的操作" |
| 自主性 | 5 行 × 陆/水两种部署成本 = 组合空间显著大于 L3；垫的时机/位置没有唯一解 |
| 心流 | W1–W2 低压力观察窗 → W3 首峰（水行裸奔教育）→ W4/W5 渐进 → W6 二幕陡升 → W7 彩排喘息 → W8 峰值，约 4 分钟内完成两个完整紧张-释放循环 |

### 3.1 降维设计：水域按「行」描述，不按「格」

L3 GDD §3.1 曾把泳池判为 C 档（>150 行），理由是"格子属性系统 + 水陆两套僵尸语义 + 尸体表现"三处独立系统都要动。本 GDD 用两条降维砍掉最贵的两块：

1. **水域全列一致 → 行级常量即可**：水域 = 第 1/3 行（0-indexed）的**全部 9 列**，不存在"同一行里水陆混排"。因此不需要 9×5 的格子属性矩阵，一行 `WATER_ROWS=[1,3]` 即可完整表达，种植校验退化为一次 `row` 判断。
2. **僵尸水陆零机制差异**：同一 STATS、同速同血同啃食逻辑，水行仅渲染差异化（可选项）。不存在"水陆两套僵尸语义"。

剩余成本 = 一张新卡的全链路（数据 + 绘制 + 种植校验 + 音效复用）+ 水面渲染。这与"LEVELS 只是数据"的架构哲学不冲突：所有新逻辑都是"读常量做分支"。

### 3.2 睡莲格语义（V12-02 必须先定案的唯一悬置点）

**种植规则矩阵**（规格侧锁死，不可协商）：

| 格状态 | 点旧 6 卡 | 点睡莲卡 |
|---|---|---|
| 陆地格（行 0/2/4） | ✅ 照常 | ❌ 拒绝（toast） |
| 水格 · 无垫 | ❌ 拒绝（toast） | ✅ 铺垫 |
| 水格 · 有垫 | ✅ 种在垫上 | ❌ 拒绝（已占用） |

任何拒绝路径**零副作用**：不扣阳光、不进 CD、不消耗选择态（E1/E2，§6.2）。

**啃食/耐久语义两案**（甲为推荐，最终以 V12-02 可实现性背书为准，见拍板项②）：

| | 甲案：垫为实体（推荐） | 乙案：垫为门槛标志 |
|---|---|---|
| 数据形态 | 睡莲 = 真实植物实体，与其上植物同格分层 | 水格布尔标志 `hasPad`，垫不是实体 |
| 耐久 | 垫有独立耐久（建议与普通植物同级，实现侧常量为准，规格不锁值） | 无耐久、不可被啃 |
| 啃食顺序 | **自上而下**：先啃上覆植物，植物阵亡后垫保留；空垫被啃 = 垫销毁（实现路径：updateZombies 啃食目标选择改倒序遍历 +1 行，对陆地格严格等价，见 §3.0） | 僵尸啃该行第一个"格内标志" |
| 上覆植物存续 | 垫在植物在；垫亡不连带（自上而下顺序天然保证） | 永远存续（垫不可摧毁） |
| 实现代价 | plants 同格双实体的分层/渲染/点击命中 | 最小：一个布尔 + 校验分支 |
| 平衡影响 | 水行防线可被啃穿 → 水税可能重复缴（压力真实） | 垫一次性投资 → 水行后期偏强（约省 50–75 税/局） |
| 对预算比的影响 | 按 §5.3 口径（含 1–2 张重铺余量） | 需求侧 -1%～-2%，可忽略 |

两案都不改变 §4/§5 的任何波次数值——这是把语义悬置到 V12-02 的前提。

### 3.3 复盘：为什么 L3 否决的泳池现在可以做

- L3 判 C 档的两个前提已失效：①"网格属性系统"被 3.1 的行级常量降维；②"水陆两套僵尸语义"被范围红线直接禁止。
- **用户已于 2026-09-18 拍板方案 A**，即明确愿意支付本节审计出的成本——GDD 的职责从"劝退"转为"把成本算清楚"（本文即算清的结果）。
- 不做的预置垫（原版泳池关开局亦无免费睡莲）：预置实体 = 新初始化逻辑，违背最小改动；开局资源判断（§5.2）已留出水行机动资金。

### 4.2 逐波压力表（三口径之一：逐波求和）

| 波 | 构成 | 只数 | interval | big | 单波压力（总 hp 口径*） | 设计意图 |
|---|---|---|---|---|---|---|
| W1 | normal×2 | 2 | 10 | — | 360 | 与 L3W1 完全同构：150 起步 + 25s 零压力窗口，足够完成陆地首葵与水行观察 |

| W8 | normal×3 + cone×2 + fast×1 + **bucket×2** | 8 | 6 | 🚩 | 2480 | **终波峰值**：单波 8 只 = 全关最高；双铁桶 = 2480 hp 为系列之最（L3W7 的 1.2 倍） |

\* 压力 = Σ(单只 hp)（normal 180 / cone 340 / fast 140 / bucket 560）；"+速度轴"表示 fast 实际威胁高于 hp 权重。水行期望命中 = 只数 × 2/5（随机行）。

**三口径独立复算互证**（本表为第一口径；第二口径类型构成；第三口径大波峰值）：

- 逐波只数：2+3+4+5+4+5+7+8 = **38**
- 类型构成：normal 16（2+2+2+3+0+2+2+3）+ cone 10（0+1+0+1+2+2+2+2）+ fast 8（0+0+2+1+2+0+2+1）+ bucket 4（0+0+0+0+0+1+1+2）= 16+10+8+4 = **38** ✓
- 逐波 hp：360+700+640+1020+960+1600+1880+2480 = **9640**
- 类型 hp：16×180 + 10×340 + 8×140 + 4×560 = 2880+3400+1120+2240 = **9640** ✓
- 大波峰值（hp 口径）：W3 640 < W6 1600 < W8 2480，严格递增 ✓

**单调性自检**：W1(2) → W2(3) → W3(4) → W4(5) → W5(4↓) → W6(5) → W7(7) → W8(8)。数量口径仅 W5 一处回落，且威胁构成上升（hp 密度 240/只 vs W4 的 204/只，fast 占半）——与 L3 同款论证。原始 hp 序列（360→700→640→1020→960→1600→1880→2480）非逐项递增，递增以**大波峰值**为准，回落波由构成补足（支柱同 L3 支柱 3）。

### 4.3 预警与节奏机制（全部沿用现有规则，零改动）

- 大波预警：`big:true` → 剩 ≤2 只时先播 2s 预警横幅（`WARN_TOTAL=2`）+ SirenLoop，清场后正式放出。
- 非大波推进：上一波队列放完 + 场上清空 + 最小喘息（第 1 波前 12s / 最后两波间 20s / 其余 16s）或 25s 兜底。
- 刷怪节奏：`interval` 经 `max(2.5, interval)` 下限保护；队列剩 >6 只时每只额外 +0.5s——W7（7 只）实际放出跨 ≈40–45s，W8（8 只）跨 ≈45–50s，终波压力被引擎自动摊薄。

### 4.4 总时长预估

### 5.2 startSun=150 的专项推导（拍板项①）

1. **隔离变量原则**：L4 的新变量是水税，开局就用 L1/L2 的熟悉锚点（150），让玩家把注意力花在水域上，而不是同时消化"起步更穷 + 水更贵"两个压力——对照实验思维：一次只动一个轴。
2. **水行机动资金**：随机行刷怪下玩家无法规划"先防哪行"。150 vs L3 的 100 多出的 50，恰好 = 一张垫 + 半张豌豆的机动资金（25+25 着陆阳），覆盖"W1/W2 僵尸落水行"的快速响应需求（垫 25 + 豌豆 100，需存量 125）。
3. **时长补偿**：本关 ≈4 分钟为系列最长，开局宽 50 对后期压力几乎没有影响（后期主导项是葵产出与水税）。
4. **关际手感差异已另有载体**：L3 用 startSun=100 做差异化，是因为 L3 没有别的新鲜感载体；L4 的差异化由水税 + 睡莲卡 + 两幕结构承担，不再需要 startSun 出力。
5. **风险熔断**：若实测开局过松（反馈"前两波无事可做"），**回调路径 = startSun 150→100**，单字段改动，SMOKE-025 T4 独立断言，不引发连锁（§9.4）。
6. **明确声明**：startSun 序列 150→150→100→**150** 是**刻意的非单调**，不属笔误，需用户拍板确认。

### 5.3 总量 38 的专项推导（反向预算法 + 水税专项）

- **经济反推（供给侧）**：起步 150 + 自然落阳（≈250s × ≈2.7/s ≈ 650）+ 向日葵产出（中后期 5–6 葵、陆 3 行足以容纳、玩家经验值高于 L3 评估期，按 L3 口径 4 葵 ≈ +550 等比放大 ≈ +850）。总供给 ≈ **1600–1700**。
- **需求测算（火力）**：L3 口径系数 ≈0.124 sun/hp（950/7660），L4 总 hp 9640 → 火力需求 ≈ **1150–1250**。
- **需求测算（水税专项）**：期望水行僵尸 ≈ 38×2/5 ≈ 15.2 只。水行防线 ≈ 每行 3 张输出 × 2 行 = 6 垫 + 1–2 张重铺余量（甲案啃食语义下垫会被啃穿）→ **6–8 垫 × 25 = 150–200**。水税占需求 ≈11–14%、占供给 ≈9–12%——这个占比就是 L4"体感变难"的精确来源，也是支柱 1 的量化表达。
- **预算比**：≈ 1600–1700 / 1350–1450 = **1.15–1.25（中值 1.2）**。比 L3 的 1.2–1.3 微降约 0.05，降幅 ≈ 水税占比——难度增量由空间轴支付，数量只做温和爬升。安全垫位于 L2 削峰后（≈1.35）与削峰前（<1.1 被用户打回）之间偏安全侧。
- **历史锚点**：33→38 = +15.2%，延续 +85% → +37.5% → +15.2% 的减速序列，远离 28 只/100 起步的削峰前红线。

### 5.4 逐波口径（资源配置视角）

- W1 结束：≥2 葵（150 起步可 3 葵烧完，或 2 葵 + 50 存量）。刻意比 L3 同期宽 50：其中 ≈25–50 是**水行机动资金**。
- W2 结束：+1 豌豆；若水行已遭袭，+垫（此时经济线会短暂落后 L3 同期——这是本关第一次"税感"体验）。
- W3（首大波）：必须已有 2+ 输出面，且水行至少 1 个输出或地瓜兜底。fast 从右缘到第 3 列 ≈13s，预警横幅 2s 后仍有充足布置窗——前提是垫已在（垫 5s CD 内可补，但垫上无植物的空垫救不了场）。
- W5 结束：5 行每行至少 1 个输出；经济线 4–5 葵。
- W6（桶回归）：1–2 双发/西瓜 + 坚果拖延（全 L3 已学）；桶若落水行，双发需垫（225 全场最贵单格投资）——本关资源管理的考点时刻。
- W7（彩排）：4 类同屏的完整阵容检查；非大波，失败成本可控。
- W8：双桶同行概率 1/5（其中同水行 2/5×2/5=4/25）；若双桶落同一水行，需该行垫上 ≥2 输出面集火（560hp ≈ 双发+豌豆 12s）。8 只 interval 6 摊 ≈49s 放出，火力成型阵容（≈5 输出含水行 + 5–6 葵 + 2 坚果/地瓜）可清。

### 5.5 interval 下限=6 的推导

- 继承 L3 结论：L4 的难是"更长的作战"，不是"更密的弹幕"。时长已 +21%，若把下限压到 5 会把 4 分钟变成弹幕关，违背系列身份。
- W6/W7/W8 的 6s + 尾重摊薄使终波 8 只实际跨 ≈49s——单位时间压力低于 L2 终波（5s×6 只），但持续更长、总量更大。
- 契约取 `minInterval ≥ 6`（§8.1 T8）；疲劳回退阀保留 W8 单波 6→5 选项（§9.4）。
