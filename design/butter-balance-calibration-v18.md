## 1. 标定协议（执行口径）

- **候选式**（全部零自由参数，plan §2 R9 原文形式）：
  - **F-A** 泊松逼近 `C = 1−(1−p)^(n·T/cd)`（plan 原文单株 `1−(1−p)^(T/cd)`，多株按泊松窗口推广）
  - **F-B** 连续更新回报 `C = n·p·T/(cd + n·p·T)`（plan 原文单株 `u=p/(cd+pT)`、覆盖率=u·T，多株按交替更新稳态占空比推广）
  - **F-C** M6 式 `C = 1−exp(−n·p·T/cd)`（v17 报告 M6 经验拟合；按 plan 要求补拟合优度：χ²/R²，df=4，残差=投影−复测）
- **参考式 GRID**（本标定新增，机制驱动、零拟合参数，**不参与通过判定**）：黄油尝试是确定性 cd 网格 + 概率掷定（源码 L1473，非泊松）⇒ 命中间隔 k·cd 服从几何分布，每次命中贡献 `min(T, k·cd)`：
  `q = 1−(1−p)^n；C = [Σ_k min(T, k·cd)·(1−q)^(k−1)·q] / (cd/q)`
  解析性质：T≤cd 时 min 恒为 T ⇒ **严格退化为线性式 n·p·T/cd**（k 求和=1）。
- **锚点复测**：5 锚点 × **48 种子**（≥24 达标）+ 每锚点 warmup=8s 对照 ×8 种子。复测值口径 = 历史锚点原生口径（覆盖率=freezeCoverage 全窗；A5 合成=unionFrac）。
- **残差口径**：`residual = 投影值 − 复测均值`（正=高估）。A5 合成投影 = 式(n=1) 冻结分量 + 同窗口实测 chill 分量（**加法**，prelude 口径 chillFrac 与冻结帧不相交；教训见 §7-③）。
- **通过判据**：全锚点 |residual| ≤ ±2pp。**禁凑数放宽**——无一通过时如实报告并给分段式建议。

## 4. 两域分界（D-1 增补 A 硬性要求）

### 4.1 分界判据

```
              ┌─ T ≤ cd（v1.6 域，如 0.27/2.5）──────────────┐
  参数 (p,T) ─┤                                              │
              └─ T > cd（v1.7+ 域，如 0.27/3.0）─────────────┘
                     │
   T≤cd 域：刷新事件【数学上不可能】（下一发黄油命中时上一枚必已过期）
           ⇒ 线性式 C = n·p·T/cd（封顶 1）解析精确
           ⇒ 实测背书：A1 全 48 种子 refresh=0/waste=0（确定性，非统计性）
           ⇒ 哨兵 A 域判据同源（prelude.runSentinel A 域恒 PASS）

   T>cd 域：刷新必然发生，被刷新吞掉的 freezeT = Σ(刷新时剩余 freezeT)
           ⇒ 一切「窗口×概率」式系统性高估；必须带浪费修正
           ⇒ 实测背书：A2–A5 refresh=81/458/858/134，全 >0（确定性方向）
           ⇒ 哨兵 B 域判据同源（每刷新浪费 ≈ T−cd，v1.7 域判 FAIL）
```

### 4.2 分界两侧机制对照表

| 维度 | T ≤ cd（v1.6 域） | T > cd（v1.7+ 域） |
|---|---|---|
| 刷新浪费事件 | 恒 0（确定性） | 必然发生（确定性） |
| 每刷新浪费额 | —（无事件） | **双峰结构**：单株/稀疏命中 = 边际档 ≈ T−cd；多株同 tick 双中/密集连中 = 「全浪费」档 ≈ T |
| 单株每刷新浪费实测 | — | 0.444s ≈ T−cd=0.4s（A2，81/81 事件全落 0.38–0.50s 带；马尔可夫 renewal 锚点） |
| 多株浪费结构 | — | A3：89.3% 全浪费档（均值 1.05s）；A4：90.6%（均值 1.30s）——n 越大同 tick 双中越频繁 |
| 可用投影式 | 线性式 `n·p·T/cd`（解析） | **GRID 修正式（§5；v1.9.0 起正式口径）**或 F-A−3pp 保守心算；**线性式禁入结论**（prelude 域判定 `projectionBranchEnabled=false`） |
| 线性式在本域的表现 | 残差 ~0（解析成立） | +2~+9pp 高估（A2 线性 +3.3pp / A3 +7.4pp / A4 +6.0pp；v1.7 调参翻车根因） |

### 4.3 分界点的Warning

- 分界是**硬边界**：T=cd 处两侧行为不连续（浪费事件从恒 0 跳变为必然发生）。调参把 T 从 2.5 抬到 3.0 这类「小改」实际跨域，投影公式必须切换，不能外推。
- 哨兵（`prelude.runSentinel`）是分界的回归守卫：v1.6 域 PASS + v1.7 域 FAIL 双域齐备才有判别力。**改动 T/cd/p 后必跑哨兵**，防代数投影前提静默失效复发。

## 5. 修正公式建议（分段式；如实标注超差，非凑数放宽）

**标定判定维持「无一候选式通过」**（F-A maxAbs 3.0pp > 2pp）。以下为分段式建议，其中 GRID 在四个纯冻结锚点仅 A2 微超 0.1pp。**【v1.9.0 立项注：GRID 已由用户拍板采纳为正式口径；本节历史判定与理由记录保持原貌。】**

### 5.1 推荐投影流程（正式口径，v1.9.0 起）

```
输入：p（黄油概率）、T（定身时长）、cd=2.6（投手攻速）、n（同目标株数）
第 1 步 判域：T ≤ cd ?
  ├─ 是（T≤cd 域）：C = min(1, n·p·T/cd)                    【解析精确，放心用】
  └─ 否（T>cd 域）：
      ├─ 精算：C = Σ_k min(T, k·cd)·(1−q)^(k−1)·q / (cd/q)，q=1−(1−p)^n   【GRID 式，k 截断 (1−q)^(k−1)<1e-12】
      └─ 心算：C ≈ [1−(1−p)^(n·T/cd)] − 0.03                【F-A 减 3pp 保守修正，仅快速估算用】
第 2 步 语义折算：上面是全窗存活靶覆盖率；若对比稳态口径再加 +1~2pp 冷启动偏置修正
第 3 步 终判：跑 tests/playtests/v18-r9b-calibration.js 同款复测（≥24 种子），公式值不作验收
```

### 5.2 为什么 GRID 被采纳（标定时判定仍 FAIL）

- 机制对齐源码：黄油掷定在**确定性 cd 网格**上（L1473 `Math.random()<0.27`，每 cd 一次），不是泊松过程——GRID 的几何间隔假设与源码机制一一对应；F-A 的泊松指数间隔是错的机制、碰巧量级接近。
- T≤cd 域解析退化=线性式（精确），**一个式子覆盖两域**，天然带分界。
- 零拟合参数（无凑数空间），χ²=8.05/R²=0.9875 为全表最优；A2 的 +2.1pp 残差在「复测 SEM 1.2pp + 口径效应」噪声量级内。
- A5 合成（加法并集口径）残差仅 −0.1pp。
- **采纳裁决（v1.9.0 立项，2026-09-23）**：标定时以「2pp 判据不放宽」为由维持建议身份；用户权衡「超差幅度在噪声带内 + 机制正确性 + 零拟合参数」后拍板采纳，超差事实在残差表保留标注。

### 5.3 GRID 的适用域警告（重要）

- **同步 cd 网格前提**：n 株必须同帧起手（注入场景）。错排/跨排/自然种植的多株 cd 相位错开，q 不再是每 cd 一次尝试——R8 类实战布防场景**不得**直接套用，须实测（M6/R8 同款）。
- **cd=2.6 标定**：全部锚点在 cd=2.6 下测得。GRID 机制式对 cd 理论上鲁棒（cd 是显式参数），但**未在 cd≠2.6 验证**；改攻速须重跑标定。
- **p 的二值性**：模型假设每次尝试独立掷定 p。源码正是如此（L1473）；若未来加「保底/连击」机制即失效。
- **不含溅射定身**：applyFreeze 唯一入口=直中（调用点=1）；若未来溅射带定身，n 的语义与浪费结构全变，须重审。

## 6. 下次调参使用指引（防翻车清单）

1. **先判域再选式**（§4.1）。T 从 <cd 改到 >cd = 跨域，投影必须换式——v1.6→v1.7 翻车的直接死因。
2. **T>cd 域禁用线性式进结论**；prelude 的 `preconditions.domain.projectionBranchEnabled=false` 是机器闸门，别绕过。
3. **F-B 已淘汰**（−4~−15pp），任何文档/代码里不要再引用 `u=p/(cd+pT)` 做投影。
4. **F-A 可作粗估但须 −3pp 修正**；报告里注明「F-A 未修正式系统性高估 +2.6~3.0pp」。
5. **口径统一**：公式值对齐「全窗存活靶覆盖率」（历史 M1/M6/M5 口径）。与稳态理论比较时另加冷启动偏置（+1~2pp）。跨口径数字禁止直接相减下结论。
6. **合成控制（corn+icemelon 类）**：prelude 口径 chillFrac 与冻结不相交 ⇒ **加法并集** `frozen + chillDisj`；v16 旧口径 slowFrac 含冻结帧 ⇒ 独立并集。两种口径差 ~12pp（§7-③），跨版本对比先换算。
7. **多株投影**用 GRID 的 q=1−(1−p)^n（同步网格）；错排/混编场景（相位不同步）公式不可用，走 R8 实测。
8. **改 p/T/cd 任一参数后**：跑哨兵（域判定）+ 重锚点复测（本脚本换锚点参数即可复用），刷新浪费结构与残差带重新登记。

## 7. 异常与教训登记

1. **首轮 A1–A4 复测 NaN**：perSeed 聚合键名与指标键不一致（`coverage` vs `freezeCoverage`）——A5 恰好同名掩盖了问题。教训：多锚点共用聚合代码时，指标键入注册表而非散落字符串。
