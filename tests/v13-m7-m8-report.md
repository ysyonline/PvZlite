**⚠️ 口径披露（重要）**：本次 bench 运行机器为 **i5-12500 ×12**，而 `perf-profile.md` §7 上一版基线是 **i3-10110U ×4**。跨机绝对帧耗时不可直接比较（本机普遍快 3–4 倍）。**有效结论 = 同机同轮五场景横向对比**：L5（E）≈ L4（D），无退化信号。`perf-profile.md` §7 已被 bench 自动回填为本机新数据（幂等覆盖旧自动段，正常）。真机 DevTools 复核仍建议发布后补。
