## 2. 新增用例验收（机器判定）

### 2.1 `REG-SLOPE-01`（几何契约）
- **必须绿**：A（L1–L4 **逐字节** `===` 恒等）· B（L5 全 45 格往返精确，**含 col4 + col5–8 判别列**）· C（lift 单调/平台恒定）。
- **判别性硬指标**：**故意把 `posToGrid` 的 `+liftX` 去掉后，本用例必须变红**（实现期自检一次，确认判别有效）。若去掉 lift 仍绿 ⇒ 用例**无效**，必须改用 col4/平台列采样重写。
- **A 的严格性**：「L1–L4 逐字节等价」用 **`===`**，不用容差。

### 2.2 `SMOKE-028`（弹道随 lift 抬升）
- **采样列 = `col6`（平台，主力种植位，`liftX=60`）+ `col4`（斜坡末列，`liftX=54`）并跑循环**（工程侧 `v13-m4-c2-5col-impl-spec.md` §2.C 指平台列偏差最大 = 68px）。
- **Part B（命中·核心）必须绿**：两列各自发射的豌豆在同行（僵尸置于植物**右侧**）命中，僵尸 `hp 180→160`。
- **Part A（发射 y 抬升）**：col6 `pr.y≈272`、col4 `pr.y≈278`（`flatY(2)−liftX−8`）。**双向守护**：既拦「未抬升」（assessment 方案①），也拦 spec §3-**B4**「重复减 `liftX` ⇒ 双重抬升」。
- **Part C（抛物·次级）**：col6 投手 cabbage 命中扣 40（对应 spec §3-B2）。
- **α/β 鲁棒**：僵尸置于植物右侧 ⇒ 无论 spec §7-1 取 **α**（命中 `−liftX(z.x)`）还是 **β**（命中 `−pr.lift0`），Part B 都应绿。（**不得**断言「僵尸越过植物到左侧仍命中」——spec 明确为物理正确行为。）
- **判别性硬指标**：**故意让 `zy`(L1073) 不抬升后，Part B 必须变红**。若仍绿 ⇒ 采样列太靠左（须用 col4/col6）。

## 5. 裁决登记与前置依赖

1. **弹道收口方案（α 地面参考 / β 发射者参考）**：工程 `v13-m4-c2-5col-impl-spec.md` §2.C/§7-1 **默认 α**（命中 `−liftX(z.x)`），team-lead 口径同 **assessment 方案②**。**SMOKE-028 Part B 对 α/β 均鲁棒**（僵尸置植物右侧）；**Part A 锁「发射 y 抬升」，拦方案①与 B4 双重抬升**。**若改判** → 删/改 Part A 并在此登记。
2. **`H=60` 是否终值**：工程 spec §1.1 已定 `ROOF_LIFT_H=60`（文件头「用户已拍板 … H=60px」）⇒ **视为终值**。**REG-SLOPE-01 Part C 仍保持 H-无关**（L1↔L5 差值黑盒，抗未来微调）；SMOKE-028 Part A 期望随 H 同步（col6 `340−H−8 = 272`、col4 `340−0.9H−8 = 278`；H=60 时即 272/278）。
3. ~~几何口径待 ADR-005 确认~~ → **已由工程 spec §1.3 消解（2026-09-19）**：`gridToPos` = `y_flat − liftX(x)`、`posToGrid` = `+liftX(x)` 反解，与「底锚 y=600」由**檐板 `#463b2b` 补厚**（spec §2.E）自洽 ⇒ **本契约（含 SMOKE-028 `272/278`）按此式成立，无待决。** 「底边统一停 y=600」指**檐板下沿**（`fillRect` 到 600），**不是**格心 y——见 spec §2.E 檐板填充伪码。**若最终实现偏离该式，回扫 REG-SLOPE-01 Part C 与 SMOKE-028 Part A。**
4. **PROBE 建议（可选·非必须）**：实现期在 `harness/index.js` 的 `PROBE_SUFFIX` 暴露 `__liftX`（+可选 `zombiesArr` 增 `y`），可把 Part C 从「差值推断」升级为「直取函数」，并支撑未来坡上命中/行走的定点断言。**不改游戏本体**。
5. **★ 第三处 L5 用例（QA 补正）**：`…-eng-assessment.md` §2.2 与 `…-impl-spec.md` §4 均称 L5 用例「唯二」（`REG-ROOF-01`/`SMOKE-027`），实测 **`REG-END-02` 亦 `setLevel(5)`**（跑 drawEnd 真帧）⇒ **实为三条**。判决：无感（仅验「render 不抛」），但**它的真帧也是 L5 新绘制的守门之一**，勿漏。
