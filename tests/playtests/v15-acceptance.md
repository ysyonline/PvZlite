## 二、逐项明细（实测数据 + 像素值 + 截图 + 判定）

### A · 选卡界面布局不重叠、不溢出 ✅ PASS
**设置**：`ownedCards`=全部 12 张、`slots`=10、`state='deck'`，`render()` 后像素判读。
**截图**：`v15-deck-layout.png`

几何断言：
- 网格行数 `rows=3`，行起点 `rowYs=[150, 254, 358]`（`DECK_GRID.y0=150`、`gh=104`）。
- 卡片绘制尺寸 150×100（源码 `fillRect(x,y,150,100)`）：
  - 行1→行2 间隙 = 254−(150+100) = **4px > 0**
  - 行2→行3 间隙 = 358−(254+100) = **4px > 0**
  - 网格底(358+100=458) → 卡槽栏顶(470+2=472) 间隙 = **14px > 0**
- 10 槽右缘 = `70 + 9×92 + 2 + 88` = **988 ≤ 画布宽 1000**（`DECK_SLOTS.x0=70, cw=92`）。

像素断言（采样点 vs 竖直渐变背景 `#2a5a1a→#4a8a2a` 在该 y 的理论值）：
| 采样点 | 实测 RGB | 背景 RGB | 判定 |
|---|---|---|---|
| 行1 卡面 (145,200) | 58,58,42 | 51,104,31 | 卡面≠背景 ✅ |
| **行间隙12 (145,252)** | **54,108,32** | 54,108,32 | **纯背景 → 不重叠** ✅ |
| 行2 卡面 (145,305) | 87,102,53 | 56,112,33 | 卡面≠背景 ✅ |
| **行间隙23 (145,356)** | **59,115,34** | 59,115,34 | **纯背景 → 不重叠** ✅ |
| 行3 卡面 (145,410) | 94,113,56 | 61,119,36 | 卡面≠背景 ✅ |
| **网格→卡槽间隙 (145,465)** | **64,123,37** | 64,123,37 | **纯背景 → 不重叠** ✅ |
| 槽位描边 (72,530)/(110,472) | 255,213,74 | — | 金色描边=卡槽栏已绘制 ✅ |
| **右缘留白 (995,490)** | **65,125,37** | 65,125,38 | **≤1 通道差 → 未横向溢出** ✅ |

> **判定：PASS**。三行互不重叠、与卡槽栏不重叠、10 槽不溢出，均以几何 + 像素双重证明。
