## 二、专项验收点（今日改动，逐项打勾）

> 每项写三件事：**怎么验** → **期望** → **异常长什么样**（后者最重要，便于区分"没做出来"和"做坏了"）

### V1 · 屏幕震动（F-04）
- **怎么验**：种地瓜（第 3 卡）等僵尸踩上去；再打到第 5 波大波预警
- **期望**：爆炸震一下（幅度小、约 0.3s 内衰减完）；大波预警启动与刷怪各震一次
- **异常**：画面持续抖不停 / 抖到看不清网格 / **通关或失败画面还在抖**（已按要求移除）

### V2 · 种植动画（F-01）
- **怎么验**：选任意卡片种下，盯着那一格
- **期望**：约 0.6 秒的「从卡片位飞向格子 → 落地缩一下 → 落定微抖」+ 落地扬尘
- **异常**：植物瞬间出现无动画 / 卡在半空不落地 / 种植后整屏卡住（曾出过 `lastDt` 崩溃，已修）

### V3 · 僵尸死亡零件（F-02）
- **怎么验**：打死普通 / 路障 / 铁桶僵尸各一只
- **期望**：血雾 + 6~7 块零件（头、身体、腿）翻滚落地淡出；路障僵尸额外掉路障、铁桶僵尸额外掉桶
- **异常**：零件不消失堆满屏 / 打死僵尸后屏幕卡顿

### V4 · 爆炸冲击波（F-03）
- **怎么验**：地瓜引爆
- **期望**：白闪一下 → 冲击波圆环扩散 → 橙黄火球（约 0.45s）→ 火星粒子 → 屏幕轻震，**五层同时在演**
- **异常**：只有一团火球没有圆环 / 白闪过曝看不清

### V5 · 大波预警（F-06，本次改为 3 秒）
- **怎么验**：打到 L1 第 5 波、L2 第 4/6 波
- **期望**：全屏压暗 + 红色横幅「一大波僵尸即将来临！」+ 警报音；**最后 1 秒**边缘渐红、倒计时数字放大、脉冲加快、轻微震动；倒计时走完 → 刷怪瞬间有**低沉冲击音**（B7，本次新补）
- **异常**：**底部出现红色报错条**（说明帧异常，立即记录并截图）/ 预警没有声音 / 预警时长明显超过 3 秒

### V6 · 波次清场门槛（本次修复重点）
- **怎么验**：每波结束后观察下一波何时开始
- **期望**：**上一波僵尸全部清空**后，才出现下一波的怪（清得快则等约 12/16/20 秒喘息）；大波会在上一波**只剩 1-2 只**时就提前拉警报
- **异常**：**上一波还有好几只活僵尸，下一波就涌出来了**（这是本次修复针对的现象，若复现请立刻记录波次号）

### V7 · 第二关新平衡
- **怎么验**：`?level=2` 直进，正常玩到底
- **期望**：开局 150 阳光（比之前宽裕）；6 波共 25 只；第 3 波 3 只；第 4 波大波只有 2 只快速僵尸；终波 6 只
- **异常**：第 3 波起仍然被快速僵尸成堆冲垮（记录是第几波、当时场上几只、你的防线配置）

### V8 · UI 细节（D-11 / D-14）
- **怎么验**：看卡片栏、左上角 HUD、预警进度条
- **期望**：卡片槽/HUD 面板是圆角，与整体风格一致；阳光数、分数、波次等**数字笔画等宽**（跳动时宽度不抖）
- **异常**：仍见直角方块突兀 / 数字变化时左右跳动

## 五、判定标准

**硬门槛（任一命中 = FAIL）**
- **F1**：出现 O1 卡死/帧异常，且同代码下 3 次复现不通过
- **F2**：核心任务全部失败（如 T1 通关），且非操作失误
- **F3**：出现 S0 级缺陷（阻断级，见 `tests/bug-taxonomy.md`）

**PASS**：T1 / T4 / T6 全 ✅，无 F1-F3，O1-O6 累计 ≤ 2 条，愿意再玩一局的人 ≥ 1
**CONCERNS**：T2/T3/T5/T8 有 ⚠ 但未 FAIL
**FAIL**：命中任一硬门槛

> 注：V 系列专项验收点若发现"异常"，按缺陷记录并定级（S0-S3），不计入 O1-O6 计数但会进质量门。
