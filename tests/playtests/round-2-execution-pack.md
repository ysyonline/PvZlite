## 四、v1.1 扩充任务详解（T9-T15，全部主测执行，除注明外）

### T9 · `?level=3` 免解锁直进第三关
- **怎么验**：地址栏 `...plants-vs-zombies.html?level=3` 打开；进一局后返回菜单再看关卡按钮。
- **期望**：免通关直接进入月夜草坪；HUD 显示第 1/7 波、开局阳光 **100**；对局结束后返回菜单，第三关按钮已解锁（`unlockedLevel` 被 max 提到 3 并持久化）。
- **负向检查**：`?level=9` 等非法值应被忽略、正常回落（不允许崩或进空白关）。
- **异常**：直进后黑屏 / 菜单第三关仍 🔒 / 非法参数把游戏带崩。
- **关联**：O5。

### T10 · 月夜冷蓝滤镜下的可读性
- **怎么验**：`?level=3` 打一整局，重点看暗绿夜色草地上：僵尸剪影、阳光光点、卡片栏文字、HUD 数字、大波预警红字。
- **期望**：滤镜压暗但**所有可交互元素依然一眼可辨**——"夜"是氛围，不是视觉障碍；预警横幅与倒计时清晰。
- **异常**：僵尸与草地融为一体 / 阳光不显眼导致漏收 / 预警红字在冷蓝底上看不清（记录具体元素 + 波次）。
- **关联**：O2 / O3。

### T11 · L3 开局压力（startSun=100）体验侧观察
- **怎么验**：L3 正常开局，只观察前 60 秒经济节奏，与 L1/L2（150 开局）对比。
- **期望**（GDD §5.2 口径）：前 25 秒全场压力恒为零（W1 仅 2 只 / 10s 间隔）；100 阳光足够 2 葵，或 1 葵 + 攒落阳出豌豆；体感应是"开局更省"，**不是**"开局更痛"。
- **异常**：开局即被迫卖血守家 / 玩家（或你自己）觉得前 60 秒无所事事过久。
- **关联**：O4。

### T12 ·（副测新手顺带观察）声音引导的教学有效性
- **怎么验**：新手正常玩，旁站记录三个声音是否被注意到——(a) 种植落地"噗"（B1）：听到是否产生"种上了"的确认感；(b) 卡片就绪"叮"（B2）：冷却好转时新手是否回头看卡片栏；(c) 阳光掉落提示（B3）：是否因声回头找阳光。
- **期望**：三个声音语义可猜、不刺耳；新手至少对 2 个声音产生正确联想。
- **异常**：新手完全没注意某声音（O3 反馈不足）/ 把某个声音误认为别的事件。
- **关联**：O3 / O5。

### T13 · 静音偏好刷新后保留（S1）
- **怎么验**：按 `M` 静音 → `F5` 刷新 → 确认刷新后依然无声（BGM、点击、种植全静）；再按 `M` 解除 → 刷新 → 确认声音恢复。主测可顺手在 DevTools → Local Storage 看到 `pvz_muted` 值随切换变化。
- **期望**：两次刷新后状态与操作一致，无需二次设置。
- **异常**：刷新后静音丢失 / 解除后仍无声 / UI 静音标识与实际行为不符。

### T14 · 最高分跨会话保留（S1）
- **怎么验**：完整打完一局**进入结算页**（胜负均可，只要走到结算）→ 记下最高分显示 → `F5` 刷新 → 再看最高分。
- **期望**：刷新后最高分保留；打出一局更高分后，最高分随之更新。
- **负向检查**：中途（未结算）刷新，本局分数不计入最高分——这是**预期行为**（仅结算落盘），不算 Bug，但请记录确认。
- **异常**：结算过、刷新后最高分归零 / 显示与实际不符。

### T15 ·（副测新手顺带观察）大波警报初体验
- **怎么验**：新手第一次遇到大波预警（L1 第 5 波）时旁站：是否停下操作看向横幅？2 秒警报（约 4 轮循环）体感吵不吵（1-5 打分）？时长够不够做出反应？警报结束瞬间应有一声低沉冲击音与刷怪同步（B7）。
- **期望**：新手能理解"要来一大波了"；警报不吵、够长。
- **异常**：新手毫无反应（警报未传达信息）/ 警报拖尾进战斗 / 无声 / 与横幅不同步。
- **关联**：O3 / O5。

## 八、判定标准（继承计划书，设计未改）

**硬门槛（任一命中 = FAIL）**
- **F1**：出现 O1（卡死或帧异常），且未能在同一份代码下 3 次复现通过；
- **F2**：核心任务全部失败，且失败原因不是玩家操作失误；
- **F3**：出现 S0 级 Bug（参考 `tests/bug-taxonomy.md`）——阻断级一票否决。

**PASS**：T3 / T4 / T5 全部 ✅；至少 1 位新手在 3 分钟内打到第 3 波或以上；玩家能自述 ≥ 2 条游戏机制。
**CONCERNS**：T1/T2 顺利但 T6 有 1 人在 3 分钟内没打到第 3 波；教学有卡壳但可绕过。
**FAIL**：任一新手 T3 或 T4 失败；或 T6 全部新手 ≤ 第 2 波。

> **v1.1 任务与补测项的处理口径（继承 Round 1 执行包对 V 系列的做法）**：T9-T15 与 R1-T7/R1-T8 **不改变上述判定公式**；其结果单独评审。若发现"异常"描述，按缺陷记录并定级（S0-S3）——命中 S0 即触发 F3 一票否决；S1 及以下进缺陷清单与下一 sprint。补测项结果由主理人**回填 `round-1-report.md`**（把"— 未单独回报"改为实测结果），用于闭合 KNOWN-ISSUES #5。
