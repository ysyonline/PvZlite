## 二、逐项明细（实测数据 + 像素值 + 截图 + 判定）

### bug1 · 震动/闪光衰减迁位

**源事实**：`loop()` 无条件段 L752–753 —— `if(screenShake.t>0)screenShake.t-=dt;` / `if(flashT>0)flashT-=dt;`，位于 `if(state==='play'&&!paused)` 之前 ⇒ 与 menu/play/end 三态无关地推进。迁位前该逻辑在 `update()`（仅 play 态跑），故 end 态震动/闪光永不衰减（bug1 根因）。

#### B1a · 三态计时器单调衰减至 0 ✅ PASS
**设置**：`clearWorld()` 后分别置 `state='menu'/'play'/'end'`，`triggerShake(6,300)` + `triggerFlash('#fff',1.0)`，实时（真实 rAF）每 50ms 采样 `screenShake.t` / `flashT` / `getShakeOffset()` 幅值。

| 态 | 采样帧 | 起 | 末 | 单调不增 | 衰减至0 | 幅值归零 |
|---|---|---|---|---|---|---|
| menu | 17 | shake 0.300 / flash 1.000 | −0.000 / −0.000 | ✅ | ✅ | ✅ |
| play | 18 | shake 0.300 / flash 1.000 | −0.017 / −0.017 | ✅ | ✅ | ✅ |
| end  | 17 | shake 0.300 / flash 1.000 | −0.000 / −0.000 | ✅ | ✅ | ✅ |

> **判定：PASS**。三态全部单调衰减至 0（末值微负系 `-=dt` 无下限截断的浮点尾差，等价于 0；`getShakeOffset` 在 `t<=0` 时硬返回 `{0,0}`，幅值=0）。**end 态衰减**即 bug1 修复的直接证据。

#### B1b · play 态闪光照度像素衰减 ✅ PASS
**设置**：`state='play'`、空世界，先取基线像素，再 `triggerFlash('#fff',0.5)` 立刻渲染取样，随后 0.95s 再取样。
- 触发前：`rgb(136,194,80)`
- 置入后：`flashT=0.500s` → `rgb(255,255,255)`（`globalAlpha=0.4·max(0,flashT/0.08)` 上限 1，全屏白）
- 0.95s 后：`flashT≈0` → `rgb(136,194,80)`（≤6 通道差复原）

> **判定：PASS**。闪光照度随 `flashT` 衰减到 0，画面像素完全复原。

#### B1c · 结算屏不再永久抖动（帧差量化）✅ PASS — 截图 `v16-bug1-end-shake.png` / `v16-bug1-end-settled.png`
**设置**：`state='end'` + `clearWorld()`（`drawEnd` 静态无动画），`triggerShake(6,300)`；整屏网格（步长 24px）最大通道差量化帧差。
- 抖动期：50ms 间隔帧差 = **213**（偏移随 `performance.now()` 变化 ⇒ 画面在抖）
- `screenShake.t` 衰减至 0：**true**
- 衰减后：50ms 间隔帧差 = **0**（画面完全静止）

> **判定：PASS**。抖动期间帧差显著非零，衰减归零后帧差为 0 —— "结算屏永久抖动" 已消除。

### bug2 · 斜坡列直射规则

**源事实**：唯一口径 `level.roof && p.col < ROOF_COLS`（`ROOF_COLS=5`，L1395/1421）；**严禁** `liftX>0`（平台列 col5–8 的 liftX 同为 60，会误伤）。撞壁三判据在 `updateProjectiles` L1528–1534：`if(pr.x-pr.x0>=30 && (liftX(pr.x)-pr.lift0>=pr.yOff || pr.x>=pr.xt))` 后 `continue` **无条件短路**命中判定。`xt=GRID_X(55)+ROOF_COLS(5)×CELL_W(90)=505`。

#### B2a · slopeWall 标记矩阵 ✅ PASS
**设置**：`level=LEVELS[5]`（屋顶），逐类型 `spawnPlant` → `updatePlant` 一次 → 读弹体字段。

| 类别 | 列 | 弹体 slopeWall |
|---|---|---|
| 直射 pea / snowpea / double | col1（斜坡） | `true` / `true` / `[true,true]` |
| 直射 pea / snowpea | col6（平台） | `false` / `false` |
| 投掷 corn / melon / icemelon / cabbage | col1（斜坡） | 无该字段（`null`，免疫） |

- **反例证据**：平台列 col6 自身 `liftX=60.00 > 0` 且 > 斜坡列 col1 `liftX=18.00` ⇒ 若以 `liftX>0` 判斜会**误伤平台列**，源码口径正确。
- 折角立面 `xt = GRID_X+ROOF_COLS*CELL_W = 505` ✅。

> **判定：PASS**。直射类按列精确标记、平台列不标记、投掷类免疫，且反例证明"禁用 liftX>0" 的必要性。

#### B2b · 撞壁消失·不命中任何僵尸（对照实验）✅ PASS

## 四、结论

**总判定：PASS（14/14）**。v1.6 三刀在真机无头浏览器下逐条通过：

- **bug1**：震动/闪光计时衰减已迁至 `loop()` 无条件段，menu/play/end 三态均单调衰减至 0；结算屏抖动在衰减后帧差=0，永久抖动消除。
- **bug2**：斜坡列直射弹按 `level.roof && col<ROOF_COLS` 精确标记，撞壁 30px 下限 + `continue` 短路确保不命中任何僵尸；平台列照常命中、投掷类免疫；直射类保留开火动作与音效。
- **corn**：数值（100/15/2.6s/溅射30·40%=6）落地；25% 黄油弹发射时掷定；命中完全定身 2.5s（三停）且与 chill 独立并存；仅黄油直中施加定身、溅射不施加；白奶酪块弹体与头顶黄油渍像素齐备。

**质量门判定**：**PASS**（advisory · 最终放行由用户决定）。无非阻塞缺口；唯一修正项为验收脚本自身的受控坐标构造，已复跑闭环，不影响源码结论。
